# Spec: 상단 바 (YGTopBar)

- 대상: `core:designsystem` — `component/ygtopbar/`
- 관련: [ADR-0010](../../../adr/0010-custom-compositionlocal-theme.md)(자체 테마) · [design-system](../../../architecture/design-system.md) · [ygiconbutton](2026-07-12-ygiconbutton.md) · [ygchipbutton](2026-07-16-ygchipbutton.md) · PR #152(`feature/#127-topbar`)

> 상태·날짜·대상·관련은 위 frontmatter가 단일 출처. 본문은 설계 내용에 집중.

> ⚠️ **as-built 정정(2026-08-01, PR #173 develop 머지)** — `YGTopBarDefault`가 **삭제**되고
> `YGTopBarEmpty`가 `rightContent: @Composable () -> Unit = {}` 슬롯을 갖는 형태로 통합됐다.
> 즉 변형은 **4종 → 3종(Back/Detail/Empty)**이고, "메뉴 + 로고 + 우측 칩" 구성은 호출자가
> `YGTopBarEmpty(rightContent = { YGChipButton(...) })`로 조립한다(첫 호출자: G-001
> [g001-group-list](2026-08-01-g001-group-list.md)). 아래 본문 중 `YGTopBarDefault` 서술은 이력이다.

## 목표
화면 상단 내비게이션 바. 좌측 아이콘 버튼 + 우측 타이틀/액션 슬롯 구성을 공유하는 **프리셋 변형**을 노출한다(작성 시점 4종 → 현행 3종). 공통 레이아웃은 private `YGTopBarContent`가 담당.

## 범위
- 포함: 변형(뒤로가기/상세/빈, 작성 시점엔 기본 포함) + 공통 레이아웃, `YGIconButton`·`YGChipButton` 재사용, 토큰 매핑, 프리뷰.
- 제외:
  - 클릭 동작(내비게이션·메뉴 열기 등) — `onIconClick`/`onChipClick` 콜백만 노출.
  - 타이틀 문구 생성 — 호출자 주입.
  - 스크롤 연동·상태(collapsing 등) — 미지원(정적 바).

## API / 인터페이스
```kotlin
// 현행(#173 이후)
@Composable fun YGTopBarBack(onIconClick: () -> Unit, modifier: Modifier = Modifier)
@Composable fun YGTopBarDetail(title: String, onIconClick: () -> Unit, modifier: Modifier = Modifier)
@Composable fun YGTopBarEmpty(          // #188로 date·day·hazeState, #194로 windowInsets 추가
    date: String,
    day: String,
    onIconClick: () -> Unit,
    modifier: Modifier = Modifier,
    hazeState: HazeState? = null,
    windowInsets: WindowInsets = YGTopBarDefaults.windowInsets,  // #194 (= WindowInsets.statusBars)
    rightContent: @Composable () -> Unit = {},
)
// 삭제(#173): YGTopBarDefault(onIconClick, onChipClick, modifier)
// 신설(#188): YGTopBarCanvas — 계약은 bar-listdate 스펙
```

### 변형 매핑
| 변형 | 좌측 아이콘 | 우측 슬롯 | 콜백 |
|------|-------------|-----------|------|
| `YGTopBarBack` | `ic_caret_left`("뒤로가기") | 없음 | `onIconClick` |
| `YGTopBarDetail` | `ic_caret_left`("뒤로가기") | `title` 텍스트(`body.b01R`, `Gray.Gray800`) | `onIconClick` |
| `YGTopBarEmpty` | `ic_hamburger`("메뉴") | **날짜 `date` + 요일 `(day)`**(#188) + `rightContent` 슬롯 | `onIconClick`, `hazeState`(#188) |
| `YGTopBarCanvas`(#188 신설) | `ic_caret_left`("뒤로가기") | `title`(`weight(1f)`, 말줄임) + `memberContent` 슬롯 | `onBackClick`, `onMenuClick`(우측 `ic_hamburger`) |
| ~~`YGTopBarDefault`~~ | ~~`ic_hamburger`~~ | ~~로고 + `YGChipButton`("새 그룹")~~ | **#173로 삭제 — `Empty` + `rightContent`로 대체** |

> 🔁 **#188 develop 머지(2026-08-04)로 이 문서의 범위가 갈렸다** — `Canvas` 변형 신설, `Empty`의 로고
> placeholder → 날짜 2텍스트, 배경 블러(`hazeState`), `YGTopBarContent`의 `contentPadding`·`trailingContent`
> 확장, `YGTopBarDefaults.BackdropBlurRadius`는 전부
> [bar-listdate 스펙](2026-08-01-designsystem-bar-listdate-components.md)이 정본이다. 이 문서는 최초 3~4변형
> 계약만 들고 있다.

## 동작 / 상태
- Stateless presentational. 각 변형은 공통 `YGTopBarContent`(private)를 서로 다른 아이콘/슬롯으로 구성.
- 좌측 아이콘: `YGIconButton(size = YGIconButtonSize.SIZE_44)`, `contentDescription` 지정(접근성).
- `rightContent`(구 `YGTopBarDefault`의 칩 자리)는 로고 `Box(weight(1f))` **뒤**, 즉 안쪽 `weight(1f)` Row
  안의 형제로 배치된다. 칩 색·문구는 호출자가 정한다(G-001은 `GrayOutline` + "그룹 추가하기").

## 레이아웃 / 토큰 매핑 (심볼명)
| 요소 | 토큰 / 값 |
|------|-----------|
| 루트 패딩 | top/bottom `padding3`, start `padding3`, end `padding7` (`YGTheme.layout.padding.*`) |
| 좌측 아이콘 | `YGIconButton`, `YGIconButtonSize.SIZE_44` |
| 타이틀 텍스트(Detail) | `YGTheme.typography.body.b01R`, `YGAtomicColors.Gray.Gray800` |
| 아이콘 리소스 | `R.drawable.ic_caret_left` / `ic_hamburger` (`ic_plus` 로고 placeholder는 #188로 날짜 표기에 밀려 사라짐) |

## 파일 구성
- `component/ygtopbar/YGTopBar.kt` — public 변형 4종(#188로 `Canvas` 추가, #173 이전엔 `Default` 포함 4종) + private `YGTopBarContent`·`Modifier.ygTopBarBackdrop`. `YGTopBarDefaults.kt`가 블러 반경 상수를 든다(#188).
- 프리뷰: `@YGPreview` + `PreviewBox`(흰 배경 위 세로 나열 — `Empty`를 슬롯 없이/칩 슬롯으로 두 번).

## 주의 / 열린 질문
- ~~**로고 placeholder**~~: ✅ **해소(#188 develop 머지, 2026-08-04)** — `YGTopBarEmpty`의 `ic_plus`
  자리가 Figma 재조회로 **날짜 표기**(`date` + `(day)`)로 확정돼 placeholder todo가 닫혔다.
- ~~**프리뷰 칩 색이 Figma와 어긋남(2026-08-01)**~~: ✅ **해소(#188)** — Figma `Button-Chip-Left` 자체가
  흰 배경 + 회색 테두리로 바뀌어 프리셋이 `CherrySubtle`→`GrayOutline`으로 교체·개명됐고, 프리뷰·호출
  화면(G-001) 모두 새 프리셋을 쓴다.
- **상단 인셋을 컴포넌트가 흡수(#194 develop 머지, 2026-08-07)**: `Empty`만 `windowInsets` 파라미터를
  갖는다(기본 `WindowInsets.statusBars`, `YGTopBarDefaults.windowInsets`). `windowInsetsPadding`이
  `ygTopBarBackdrop`보다 **안쪽**이라 틴트·블러는 인셋 영역까지 덮는다. 나머지 3변형은 파라미터가 없어
  같은 화면 관용구를 쓸 수 없다 → [open-questions](../../../synthesis/open-questions.md) [2026-08-07].
- **원자 색 직접 참조(과도기)**: 타이틀 색 `YGAtomicColors.Gray.Gray800` 직접 참조.
- **프리뷰 방식**: `@YGPreview`+`PreviewBox` 표준(#158 이후 유지, #188 추가 프리뷰도 동일).
