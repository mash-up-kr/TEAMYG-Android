# 공지사항 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 설정 화면 '알림 설정' 아래에 '공지사항'(+`YGChipNew`)을 추가하고, 공지 목록 → 상세 네이티브 화면을 Mock Repository 위에 만든다.

**Architecture:** domain(`NoticeVO`·`NoticeRepository`·UseCase 2개) → data(Mock `NoticeRepositoryImpl`) → 새 모듈 `feature/app/notice`(api + impl, MVI ViewModel 2개) → `feature/app/setting`이 `NavKeyNoticeList`로 진입. 알림 설정(#673)과 같은 계층 구조·패턴을 따른다.

**Tech Stack:** Kotlin, Jetpack Compose, Hilt(`@AssistedInject` — 상세 ViewModel), Navigation3 `NavKey`, MockK + Turbine + `MainDispatcherRule` 단위 테스트.

**Spec:** [`docs/superpowers/specs/2026-11-07-notice-design.md`](../specs/2026-11-07-notice-design.md) · 코드 주석 규약 [`docs/code-conventions.md`](../../code-conventions.md)
