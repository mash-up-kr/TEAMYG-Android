# Empty 동작 명세 v0.3 (G-001-Empty)

## 요약

그룹이 0건일 때 `G-001`에서 재생되는 **빈 상태 애니메이션**을 정한다. 더미 그룹
셋이 차례로 내려오고 안내 툴팁이 뒤따른다. 카드 일자 **26.10.05**, `v0.3`, 작성자
`DSN-A`, 개정이력은 **"닫기 조건 변경"** 한 줄이다. Figma 그룹 목록 페이지에서
옮겼다.

**UX_1의 `G-001` Empty Case다.** [[src-회의록-2026-09-29-회의]]가 UX_1 범위를
토핑 추가·편집 흐름과 `G-001` Empty Case로 정했고, 둘 다 10/15에 배포됐다
([[src-회의록-2026-10-20-회의]]).

**`v0.1`·`v0.2`는 위키에 없다.** 개정이력도 `v0.3` 한 줄만 보인다.

## 판본 관계 — 대체로 묶지 않았다

같은 `G-001-Empty`를 다루는 문서가 이미 둘 있다.

| 문서 | 작성자 | 범위 |
|---|---|---|
| [[src-G-001-Empty-툴팁-노출-조건-정책-v0.1]] (07-22) | `DSN-B` | 툴팁의 **노출·닫기 조건** |
| [[src-G-001-무한파르페-정책-v0.4]] (09-20) | `DSN-B` | 툴팁 위치·X 없음·딤 없음 |
| **이 문서** (10-05) | `DSN-A` | 더미 그룹 + 툴팁 **애니메이션**과 닫기 |

**제목도 작성자도 다르고 대체 선언도 없다.** 개정이력의 "닫기 조건 변경"이 툴팁
`v0.1`의 닫기 조건을 바꾼 것으로 읽을 수도 있지만, 이 문서의 `v0.1`이 그 툴팁
문서인지는 확인되지 않는다. 그래서 셋 다 현행으로 둔다.

## 노출

**그룹 목록이 비어 있을 때 진입하면 1회 재생**한다. 앱을 처음 열 때만이 아니라
**탭 전환 등으로 화면에 들어올 때마다** 포함한다 — 툴팁 `v0.1`의 "0건이면 항상,
최초 1회 플래그 없음"과 같은 방향이다.

## 타임라인

원본이 이미지로 넣은 표를 옮겼다.

| 요소 | 구간 | 동작 |
|---|---|---|
| 초기 대기 | 0~0.5초 | 빈 화면. 더미 그룹·말풍선 숨김 |
| 왼쪽 상단 그룹 | 0.5~1.5초 | 아래로 이동하며 페이드 인 |
| 오른쪽 중단 그룹 | 1.0~2.0초 | 같음 |
| 왼쪽 하단 그룹 | 1.5~2.5초 | 같음 |
| 상단 안내 말풍선 | 2.5~3.0초 | 제자리에서 페이드 인 |
| 전체 표시 완료 | 3.0초~ | 최종 상태 유지, 터치 대기 |

**더미 그룹이 좌·우·좌로 놓인다** — [[infinite-parfait]]의 지그재그 배치를 빈
목록에서 미리 보여 주는 셈이다.

### 그룹

- 시작: 최종 위치보다 **60 위**, 불투명도 0%. 끝: 최종 위치, 100%.
- 이동과 불투명도를 **1,000ms** 동안 함께 바꾼다. 그룹마다 **500ms 간격**으로
  시작해 앞 그룹이 끝나기 전에 다음 그룹이 나온다.
- 이징 `cubic-bezier(0, 0, 0, 1)`. 60은 Figma 기준값이고 구현은 상대 이동 Y
  `-60 → 0`이다.

### 툴팁

- 위치 고정, 불투명도 0% → 100%. 시작 **2,500ms**, 지속 **500ms**.
- "원본 이징"이 Spring(mass 1, stiffness 80, damping 20)이다.

## 닫기

- **화면을 탭하면 더미 그룹과 툴팁이 함께 0.3초 디졸브로 사라진다**(Ease-out
  `0, 0, 0.58, 1`).
- 애니메이션 도중에도 햄버거·`그룹 추가하기` 버튼은 동작한다.
- 도중에 `그룹 추가하기`를 누르면 애니메이션이 **재생 완료 상태로 바뀐다.** 그룹
  추가로 넘어가지 않고 딤을 탭해 홈으로 돌아오면, 터치 제한이 풀린 완료 상태가
  유지된다.
- 애니메이션이 끝난 뒤 화면을 탭하면 사라진다.
- 도중에 백그라운드로 나갔다 돌아오면 재생 완료 상태가 된다.

## 기존 위키와 어긋나는 것

> ⚠️ [2026-11-13] [[src-G-001-Empty-툴팁-노출-조건-정책-v0.1]] 와 상충 — 닫기가
> 그쪽은 **툴팁 외 영역 클릭**, 이 문서는 **화면 탭**이고 더미 그룹까지 함께
> 사라진다 → [[open-questions]]

- **툴팁 하나였던 빈 상태가 연출이 됐다.** 툴팁 `v0.1`과 무한 파르페 `v0.4`는 툴팁만
  적었다. 이 문서는 **더미 그룹 셋**을 더한다. 더미 이미지는 같은 페이지의
  더미데이터 섹션에 있다.
- **툴팁 문구는 여기에도 없다.** 위치(상단 안내 말풍선)와 타이밍만 있다
  ([[open-questions]]).
- **"화면 탭"에 툴팁 자체를 누르는 것이 들어가는지**가 원본에 따로 없다. 툴팁
  `v0.1`은 툴팁 밖만 셌다.
