# 회의록 2026-11-03 전체회의

## 요약

2026년 11월 3일(화) 22:30 전체회의다. **텍스트 업로드 배포 뒤 첫 피드백**을 받고,
[[src-회의록-2026-10-20-회의]]의 우선순위에서 착수한 네 건(푸시 인앱 제어,
공지사항, 초대코드 공유 방식, 카메라 줌)의 담당을 정했다. 잊혀 있던 **캔버스
인스타 스토리 바로공유**의 작업 여부도 올라왔다.

## 결정 사항

### 텍스트 배포 후 피드백 ("주변 피드백 + 나도 느낀 점")

| 피드백 | 결정 |
|---|---|
| 텍스트 색상이 너무 적다 | **"일단 좋은데 다른거 끝내고 하자(언젠가하자)"** — 구버전 대응, 색상 범위, UX 개선을 먼저 논의해야 함 |
| 캔버스 배치 시 가운데 정렬, 수직/수평 확인 | 추진. Android `AOS-B`, 디자인 `DSN-B` |
| 줄바꿈이 마음대로 안 된다 | **"스루"**. 추측 원인: 글자 크기 24px 고정 + 영역 초과 시 자동 줄바꿈. 핀치로 줄여도 포커스하면 24px로 돌아와 다시 자동 줄바꿈 |
| 100자가 너무 적다 (줄 수가 늘면 글자가 작아지는 것은 구현됨) | **500자** ("일주일안에 가능") |

### 사이드 메뉴 개편 (푸시 인앱 제어)

- 디자인·정책 완료. 알림 설정, 공지사항, **아동 안전 정책(Android만)**이 더해지며
  앱 사이드 메뉴가 무거워졌다.
- 그래서 **웹뷰로 띄우는 개인정보처리방침·이용약관·아동안전정책·오픈소스
  라이선스를 묶어 아래로** 보내는 안을 냈다. 별로면 이전 버전으로 작업(이전 버전
  유지). 담당 Android `AOS-A` / iOS `iOS-A` / Spring `SPR-A`.

### 공지사항

- 디자인·정책 완료. 담당 Android `AOS-A` / iOS `iOS-B` / Spring `SPR-A`.
- NEW 표시: ~~일주일 간 new 보여줌~~ → **"14일 지나면 new 안보이게, 클릭해서 봐도
  new 안보이게"**.
- 화면 형태: ~~웹뷰~~ → **네이티브**.

### 초대코드 공유 방식 변경 / 카메라 줌

- 둘 다 디자인 반영 완료. 초대코드는 Android `AOS-C` / iOS `iOS-A`, 카메라 줌도
  같은 둘.

### 캔버스 인스타 스토리 바로공유

- "뭔가 잊혀져 있었음… 작업 여부부터 결정해야 함" → **"영상 되면 사진+영상
  아니면 사진만 (확인후 공지)"**. Android `AOS-B`.

### 기타 발견 이슈

- **수동 누끼 줌인 배율이 너무 작다**(현재 3배) → 확대 가능, 배율은 추후 공지.
- 누끼 로딩 서브텍스트 띄어쓰기 "주세요 ..." → "주세요...".
- **마감 알림 기준 결함:** 전날 누가 쌓았다가 다 지워 마감 시 변경이 0개면
  **"0명의 친구들과 쌓았어요"** 알림이 뜬다. 원래는 **마감 시 변경사항이 1개
  이상인 가장 가까운 과거 날짜**의 알림이 떠야 한다 → 서버 확인.
- 홍보 릴스: 7달러 × 5일. "3초간 문제정의 및 공감으로 어그로, 이후 앱 소개".

## 범위·정책에 미친 영향

- **텍스트 상한이 100자에서 500자로 5배가 됐다.** 근거는 사용 피드백("생각보다
  100자 너무 적음")과 이미 구현된 자동 축소다
  ([[src-회의록-2026-10-04-텍스트-기능-정의-회의]]).
- **텍스트 기본 글자 크기가 24px 고정으로 드러났다.** 원본 스스로 "추측"이라
  적었고 줄바꿈 제어는 범위 밖으로 넘겼다.
- **텍스트 색상 확대는 무기한 보류다** — "언젠가하자".
- **외부 공유가 범위 안으로 들어왔다.** 캔버스를 인스타 스토리로 바로 보내는
  기능이 작업 대상이 됐고, 초대도 복사에서 공유로 바뀐다
  ([[src-회의록-2026-11-10-회의]]). [[mvp-scope-limits]]의 "외부 공유: 기능
  없음"(v7)이 뒤집힌다.
- **사이드 메뉴(`S-001`)가 커졌다** — 알림 설정(`S-105`,
  [[src-푸시알림-인앱-알림-제어-정책-v0.3]]), 공지사항(`S-106`,
  [[src-S-106-공지사항-운영-정책-v0.3]]), 아동안전정책(Android). v7의 `S-001`
  다음 단계는 `S-002`~`S-005` 넷이었다([[account]], [[screen-id-scheme]]).
- **푸시 프라이밍에서 미룬 사람이 다시 켤 자리가 생긴다.**
  [[push-notification]]이 "나중에 켜는 경로가 없다"고 적은 공백을 알림 설정
  화면이 메운다.
- **마감 알림 문구의 기준 날짜 규칙**이 처음 적혔다 — "마감 시 변경사항이 1개
  이상인 가장 가까운 과거 날짜"([[canvas]]).
- 수동 누끼(`C-104`)의 줌 배율 3배가 처음 수치로 나왔다
  ([[topping-placement-pipeline]]).
