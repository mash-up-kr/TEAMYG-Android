# 5/7 회의록 (2026-05-07)

## 요약

전체회의다. 2026년 5월 7일 21:30, Discord, 전원 참석. [[src-회의록-2026-04-30-회의]]에서
배정한 **기술 검토 결과를 공유하고 MVP를 확정했다.**

## 기술 검토 결과

| 항목 | 결과 | 단서 |
|---|---|---|
| 배경 제거(누끼) — iOS | 가능 | 사물을 꾹 눌러 선택. 박스 형식 제공은 검토 |
| 배경 제거(누끼) — Android | 가능 | **촬영 환경에 따라 품질 편차.** 인식 대상은 사용자가 선택만 가능(자동 인식 불가). **사람 인식은 확인 필요** |
| 누끼 테두리(Stroke) | 가능 | 색상·곡률·두께는 고정값. 색·두께 등 일부 자유도 가능 |
| 사용자 정의 배경 | 가능 | 컬러·사진 배경 모두. 유저 자유 배치. 결과물 이미지 변환. **위치 지정 템플릿은 MVP 제외** |
| 비회원 접근·작성자 표시 | 가능 | **MVP: 접속할 때마다 새 임시 코드값 부여, 앱 삭제 시 소멸.** 회원가입 없이 임시 식별값으로 그룹·작성자 관리 |

## 결정 사항 — MVP 최종 확정

**포함**

- 촬영 → 누끼 — 촬영 즉시 배경 제거. **수동 편집 없이 고품질 보장.**
- 그룹 캔버스 — 친구들과 캔버스 공유, 누끼 스티커 올리기. 즉시성·내부 공유성
  최우선. **실시간성 vs 공유 방식은 추가 확정 필요.**
- 배경 & 테두리 — 컬러·사진 배경 + 테두리. 자유 배치.
- 갤러리 저장 — 인스타 직접 연동 배제, 갤러리 경유 공유.
- 작성자 표시.

**제외** — 자동 배치(기술 문제), 위치 지정 템플릿.

**추후 검토** — 연속 사용 보상, 테두리 자유도 확장(MVP는 고정값), **비회원 영구
식별**(앱 삭제 후에도 유지되는 식별값).

## 범위·정책에 미친 영향

**4/30의 "템플릿 4~6개"가 일주일 만에 빠졌다.** 위치를 정해 주는 템플릿이 MVP에서
제외되고 자유 배치만 남았다. 이유는 "위치 배치 기능은 MVP에서 제외"라는 동어반복
뿐이다([[mvp-scope-limits]]).

**비회원 접근이 MVP 방식으로 채택됐다가 기능정의서에서 사라졌다.** 이 회의는
임시 코드값으로 비회원도 그룹·작성자 기능을 쓰게 했는데, 9일 뒤
[[src-회의록-2026-05-16-기능정의서-회의]]의 초안은 **카카오·애플 소셜 로그인만**
둔다. 그 사이 결정을 바꾼 기록이 이 범위에 없다 — [[account]]가 "소셜 로그인으로만
만들어진다"고 적는 상태의 출발점이 여기서 갈린다.

**테두리 자유도는 이 회의에서 "고정"이었다.** 뒤의 정책서는 테두리를 `2px ~ 50px`로
조절하게 한다([[src-C-104-누끼-편집-정책-v0.1]]) — MVP 이후로 미룬다던 자유도가
설계에 들어왔다.

**Android 누끼의 한계가 이때 이미 적혔다** — 환경에 따른 품질 편차, 자동 인식
불가, 사람 인식 미확인. 뒤에 수동 누끼 편집(`C-104`)이 들어온 배경으로 읽을 수
있으나 원본이 그렇게 연결하지는 않는다([[topping-placement-pipeline]]).
