# 무한 파르페 정책 설계 v0.3 (G-001)

## 요약

`G-001` 정책 설계서의 `v0.3`이다. [[src-G-001-무한파르페-정책설계-v0.2]]를 전면
대체한다 — 문서명과 목차 뼈대가 같고 `v0.3`을 제목에 달았다.

**이 위키가 한 소스에서 받은 가장 많은 종결이다.** 미결 다섯이 닫히고, **앞서
해소한 것 하나가 뒤집힌다.**

**날짜도 작성자도 없다.** `v0.2`와 같다([[open-questions]]).

## 닫힌 것

| 무엇 | `v0.3`의 답 |
|---|---|
| 좌/우 인셋 28 대 4 | **4 확정.** 기준은 **전체 템플릿(가로 324.3)** |
| 크림 가로 길이 1안 대 2안 | **고정 이미지 에셋 + 중앙 정렬.** 1안(화면 폭 추종) **폐기 명시** |
| 그룹 데이터 캐싱 여부 | **캐싱 안 함** (매번 재조회) — "종결" |
| `Right` 좌표가 서술과 어긋남 | **실측 기준 `Left y + 86`**이라 직접 적었다 |
| 6타입 중 `1`·`2`·`3` 선택 | **랜덤 부여 확정** — 아래를 본다 |

## 앞서 해소한 것이 뒤집혔다

**`v0.2`의 "변형 시드는 그룹 ID 고정" 서술이 폐기됐다.**

> 변형 번호(1/2/3)도 **함께 랜덤 재부여된다** (그룹 ID 고정 시드 아님). 구 "변형
> 시드는 그룹 ID 고정이라 유지" 서술 **폐기**.

이 위키는 그 서술을 근거로 "6타입 중 `1`·`2`·`3`을 고르는 규칙"을 **해소**로
기록했다. **그 해소 메모가 틀렸다** — 정확히는 당시 소스가 그렇게 적었고 `v0.3`이
그것을 뒤집었다.

**해소를 취소하지 않고 답을 고쳐 적는다.** 물음은 닫혔고 답이 바뀐 것이다
([[open-questions]]).

### 랜덤이되 재추첨 시점이 정해졌다

- `Left` 토핑은 `Left-1~3`, `Right` 토핑은 `Right-1~3` 중 **하나를 랜덤 부여**
  받는다.
- 정렬이 활동 최신순이므로 **새로고침으로 순서가 바뀌면 타입도 바뀐다.**
  원본의 예시 — 3번째 활동이던 그룹이 `Left-3`이었다가 5번째로 밀리면
  `Left-1`·`2`·`3` 중 하나로 다시 정해진다.
- **재추첨 시점은 목록 조회 응답 1회다.** 리렌더나 셀 재사용에서 다시 뽑는 것은
  **금지**다.

**근거가 적혀 있다** — "**회전각 튐 방지**". 스크롤만 해도 토핑이 흔들리는 것을
막는다.

**여섯 번째 근거 있는 결정이고, 구현 실패를 미리 막는 종류다**
([[spec-version-history]]).

## 좌표 컨테이너가 크림이 아니라 템플릿이다

**인셋이 무엇에 대한 값인지 처음 밝혔다.**

- 기준은 **전체 파르페 템플릿**(체리~접시를 포함한 고정 이미지 영역)이고 가로가
  **324.3**이다.
- `Left` = 좌측 인셋 **4**(x=4), `Right` = 우측 인셋 **4**(x=160.3).
- **화면 기준이 아니다.**
- `Left`↔`Right` 가로 관계는 **3.7(겹침)**이고, 템플릿 폭에서 자동으로 나오는
  **파생값**이라 직접 지정하지 않는다.

**토핑과 칩이 크림 폭을 넘는 것은 정상 동작이다.** 경계는 크림이 아니라
템플릿이다.

**이것이 크림 가로 길이 미결까지 함께 풀었다.** 크림이 고정 이미지라 폭이 정해져
있고, 토핑 좌표는 템플릿을 기준으로 잡으므로 둘이 어긋나도 문제가 아니다 —
원본이 "파생 이슈 해소"라 적고 테스트로 확인했다고 밝혔다.

## 크림은 늘어나지 않는다

- **고정 이미지 에셋**이고 비율이 고정이다.
- **화면 폭에 비례해 늘어나지 않는다.** 넓은 기기에서는 좌우 여백만 늘어난다.
- **중앙 정렬**이다.
- **1안(크림 가로폭 = 그리드 전체 크기 / 화면 폭 추종)을 폐기**한다고 명시했다.

[[src-G-001-무한파르페-정책설계]](06-13)가 1안·2안을 남기고 "개발해보고 안되면
패스 가능"이라 적은 것이 석 달 만에 닫혔다. **`v0.2`에서 항목째 사라져 "답 없이
사라진 서술"로 기록했던 것이 되돌아와 답을 얻었다** — [[purpose]] 규약대로
붙들고 있었기에 닫히는 것을 볼 수 있었다.

## 상태가 둘 늘었다

| 상태 | 화면 표현 |
|---|---|
| **특정 토핑 조회 실패** | 토핑 조회 실패 그래픽. **그룹 칩은 정상 노출** |
| **특정 토핑 내 이미지 없음** (아직 아무도 토핑을 올리지 않은 그룹) | **토핑 템플릿 그래픽** |

**빈 그룹에 놓일 템플릿이 6종이고 전부 디저트다** — 딸기 / 키위 / 오레오 /
딸기과자 / 파랑젤리 / 노랑젤리.

**기능정의서 여섯 판본 어디에도 없는 기능이다.** `G-001`의 `Empty Case`는 가입
그룹이 0건일 때였고, 이것은 **그룹은 있는데 토핑이 없을 때**다.

[[parfait]]의 디저트 은유가 또 한 층 내려왔다. `C-301`이 "캔버스 편집 모드"로
물러선 판본과 같은 시기에 이쪽은 늘었다([[spec-version-history]]).

## 저개수 기준이 N=3까지로 넓어졌다

| | [[src-G-001-무한파르페-정책설계-v0.2]] | 이 문서 |
|---|---|---|
| y +12 내림 | `N = 1`·`N = 2` | **`N = 1`·`2`·`3`** |
| 기준 | 여백 고려 | **스크롤이 없는 구간 전부** |

`N = 3`이 +12 무리에 들어왔다. **기준이 "여백"에서 "스크롤 발생 여부"로 다시
적혔다** — 스크롤이 생기는 `N ≥ 4`부터 기준 y를 그대로 쓴다.

첫 토핑 y가 `N ≥ 4`에서 **268**, `N ≤ 3`에서 **280**인 것은 같다.

## 접시 갭의 부호가 바뀌었다

| | `v0.2` | 이 문서 |
|---|---|---|
| 항목명 | 접시 ↔ 스크롤 인디케이터 | **접시 하단 갭** |
| 값 | 최소 **-16** | 최소 **16** |

**음수에서 양수가 됐다.** 다른 두 갭(-65, -48)은 그대로 음수다. 겹침을 뜻하던
값이 여백을 뜻하게 된 것인지, 부호가 정정된 것인지 적혀 있지 않다
([[open-questions]]).

## 여전히 전파되지 않는 것

**간격 `v0.3`의 정렬 타이브레이크가 없다.**
[[src-G-001-무한파르페-간격-정책-v0.3]](07-27)이 "활동순이 밀리초까지 같으면
그룹 생성일시 최신순"을 더했는데, 이 문서의 §3은 **"활동순 확정(투표 9인 전원
일치, 2026-06 종결)"**까지만 적는다.

**전파 실패가 반대 방향으로도 일어난다.** 앞서는 정책설계가 확정한 시작 사이드와
`Chip` 기준점이 간격 계열에 닿지 않았고, 이번에는 간격 계열이 더한 타이브레이크가
정책설계에 닿지 않았다([[spec-version-history]]).

**`Chip` 배치 기준점은 이 판본에도 없다.** `v0.2`에서 항목째 사라진 뒤 돌아오지
않았다.

## 위키에 없는 문서를 셋 가리킨다

| 가리킨 곳 | 무엇 |
|---|---|
| `raw/G-001-Empty-툴팁-정책-v0_1.md` | `N = 0` 안내 툴팁 |
| `raw/G-001-토핑-정책-v0_2.md` §4.2 | 타입 재추첨 상세 |
| `raw/G-001-무한파르페-간격-정책-v0_2.md` | 좌표 상세 수치·산식 |

앞의 둘은 **`wiki/raw/`에 없다.** 토핑 정책은 `v0.1`까지만 들어와 있다.

마지막 것은 **한 칸 뒤를 가리킨다** — 간격 정책서는
[[src-G-001-무한파르페-간격-정책-v0.3]](07-27)이 현행이다.

## 참조가 다섯 번째로 빗나갔다

Timestamp 텍스트 컬러가 또 **"프로필 이미지 및 토스트 닉네임 텍스트 컬러 규칙"**을
따른다고 적는다. `Grouptag-Chip`은 07-17에
[[src-S-101-프로필-이미지-및-그룹칩-내-타임스탬프-컬러-규칙-v0.1]]로 이관됐다
([[spec-version-history]]).

## 그대로인 것

- 지그재그 배치, `index 0`은 `Left` 고정, `index % 2` 구분.
- 좌표 — 첫 토핑 y 268/280, 같은 side 갭 -12, `Left` 268·416·564,
  `Right` 354·502·650, 체리↔첫 토핑 -65, 마지막 토핑↔접시 -48.
- 토핑 프레임 160×160, `Img` 96×96, **오버플로우 없음**(구 clip OFF 정책 삭제),
  6타입 상수 여섯 줄. `Left-3`와 `Right-3`가 여전히 같은 값이다.
- 그룹명 80px 초과 시 `...`(구 6자 기준 폐기), 상대 시간 표, NEW 판정.
- 크림 개수 0~3 → 3개, 4부터 1:1.
- 자동 재조회 확정, 이미지 뷰어 정책 삭제 확정, 체리 `TBD`, 접시 기능 없음.
- Z-index 넷.
- 지그재그 재배정을 "버그 아니라 정상 동작"으로 명시.

데이터 모델에 **노출 열**이 붙었다 — 그룹 ID만 미노출이고 나머지 셋은 노출,
활동 시간은 상대시간이다.

## 미결

- 접시 하단 갭이 -16에서 16으로 바뀐 이유가 없다.
- `Chip` 배치 기준점이 두 판본 연속으로 없다.
- 간격 `v0.3`의 정렬 타이브레이크가 이 문서에 닿지 않았다.
- 가리키는 문서 둘이 `wiki/raw/`에 없다.
- Timestamp 컬러 참조가 옛 문서명을 가리킨다.
- 날짜와 작성자가 없다.

전부 [[open-questions]]에 있다.
