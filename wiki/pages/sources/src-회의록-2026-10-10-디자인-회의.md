# 회의록 2026-10-10 디자인 회의

## 요약

2026년 10월 10일(토) 22:00 디자인 회의다. [[src-회의록-2026-10-06-회의]]가 정한
텍스트 기능(수정 불가 / 텍스트 개체 저장 / 폰트 고정, SUIT 후보)을 이어받아
**와이어프레임 품평**, **폰트 확인**, 첫 업로드 대책 두 건의 **담당 배정**을 다뤘다.

**원본의 결정 칸이 대부분 비어 있다.** 체크리스트와 목적 달성 항목은 체크됐으나
품평 결과 표, SUIT 라이선스 세부, 일·중 폰트 선택, 폴백 순서의 `결정` 칸이 모두
공란이다. 공란은 "미정"으로 읽는다([[purpose]]).

## 결정 사항

### 와이어프레임에 반영됐다고 확인된 것

체크된 항목이다 — 이전 두 회의의 확정 사항이 그대로 와이어프레임에 들어갔다.

- 시스템 키보드 / 띄어쓰기 포함 100자(줄바꿈 1회 = 1자) / 이모지 1개 = 1자
- 정렬 좌·중·우
- 텍스트 테두리, 텍스트 배경(네모칸), 배경 테두리(디자인 시도 후 판단)
- 이동 한 손가락 / 크기·회전 핀치(캔버스 배치 시) / 캔버스 밖 클립
- **첫 진입점 `Canvas-Menu` 2단 → 3단**
- **업로드 후 수정 불가에 맞는 흐름 — 수정 버튼 없음**

품평 결과 표(화면/피드백/결정)는 빈 행 하나뿐이다.

### 폰트

- SUIT는 **SIL Open Font License 1.1**이다(저작권자 SUNN, 2022). 상업 사용·앱
  번들·수정 배포·지원 문자 칸은 **비어 있다.**
- 일본어 후보로 **LINE Seed JP**(OFL) 한 줄이 있다. 출처 목록에는 Noto Sans JP,
  Zen Maru Gothic, Noto Sans SC/TC가 있으나 표에는 없다. 중국어 후보 표는 비었다.
- 같이 정해야 할 것으로 넷을 들었다 — 일본어 지원 여부, 중국어 범위(간체 / 간체 +
  번체 / 제외), **번들 vs OS 폴백**(번들은 가변 폰트 기준 10~18MB, 서브셋 필요 /
  폴백은 용량 0이나 기기별 자형이 다름), 폴백 순서(SUIT → 일본어 → 중국어).
  **네 칸 모두 결정이 비었다.**

### 담당 배정

| 건 | 담당 | 예상 디자인 완료일 |
|---|---|---|
| `C-001` Empty state 더미 배경 | `DSN-B` | 다음 회의에서 텍스트 기능 개발 기간 보고 정함 |
| 홈 화면 위젯 (iOS) | `DSN-A` | 같음 |

- 텍스트 추가 기능 디자인 일정: **10/15(목)**.

## 범위·정책에 미친 영향

- 텍스트 기능의 화면 흐름이 "수정 버튼 없음"으로 고정됐다 —
  [[src-회의록-2026-10-06-회의]]의 수정 불가 결정이 UI로 내려왔다([[canvas]]).
- **일본어·중국어 지원은 미정으로 남았다.** 10-04가 지원 언어를 한/영/일/중으로
  정했고 10-06이 "안 되면 제외"를 달았으나, 이 회의는 선택지만 표로 남겼다. 이후
  회의록 어디에도 결론이 없다.
- 위젯과 Empty 더미 배경은 담당만 정해졌다. [[src-회의록-2026-10-20-회의]]의
  우선순위에서 각각 6위·5위로 내려간다.
