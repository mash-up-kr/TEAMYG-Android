# 5/24 플랫폼장회의 — 인터뷰 인사이트와 기획 정리

## 요약

2026-05-24 22:30 Discord 플랫폼장회의. 회의 목적이 원본 머리에 적혀 있다 —
**외부에서 '사진 편집 앱'으로 오해하는 상황을 타개하고, '공유 캔버스 SNS'로서의
정체성을 팀 안에서 맞추고 기획을 픽스한다.**

하위 페이지 둘이 본론이다.

- **인터뷰 인사이트** — [[src-회의록-2026-05-23-인터뷰-세션]]의 종합.
- **파르페 기획 정리** — 한 줄 정의와 Is / Is Not 표.

**[[purpose]] 핵심 질문 2(누구를 위한 것인가)에 대한 이 위키의 첫 원본 근거다.**
기능정의서 여섯 판본과 정책 설계서 어디에도 없던 사용자 정의와 불편이 여기
적혔다.

## 누구를 위한 것인가 — 인터뷰 인사이트

### 대상

**"친밀한 폐쇄 그룹"을 원한다는 가설이 검증됐다**고 원본이 적었다 — 인스타그램처럼
모두에게 전시하는 것이 아니라, **단체로 친한 사람들, 여행 동행** 같은 묶음이다.
이것을 근거로 **MVP 12명 인원 제한을 유지**한다.

### 불편

**완벽한 피드 전시가 주는 피로감**이다. 인터뷰 발언 — **"멋진 것만 올리고 싶어
스스로 만족할 때까지 잘 안 올림."**

### 밀고 갈 정체성

인터뷰 어휘 **"롤링페이퍼 느낌"**, **"피그마에 엽사 가져와서 노는 게 재밌음"**을
핵심으로 삼는다. **결과물이 아니라 '노는 과정' 자체가 핵심 가치**라고 적었다.

반대로 외부 인지는 피그마·셋로그·사진 편집 앱 사이에서 표류 중이라고 진단했다 —
인터뷰어가 "이미지 실시간 편집 서비스인지, 공동 캔버스인지 확실히 해야 함"이라
지적했다.

### 위험 신호 (UT 검증 대상, 보류)

- **특별한 날에만 쓰는가** — 사용자들이 기념일·여행 같은 '특별한 날'을 언급했다.
  매일 열리는 일상 앱이 되려면 **"평범한 화요일에도 이 앱을 켤 것인가"**를 1차
  UT에서 검증해야 한다. 이 시점의 원본은 "매일 자정 열리는"이라 적는다 — 하루
  경계가 03시로 옮겨지기 전이다([[src-회의록-2026-06-04-회의]]).
- **UT 도입 멘트** — "사진 편집 앱이 아니라"는 부정어가 오히려 편집 앱 프레임을
  씌운다. "친구 3명이 단톡방처럼 모인 빈 캔버스에 그날의 사진을 올리며 노는
  공간"으로 상황을 준다.

다만 원본이 이 절 제목에 **"일단 UT 정보가 너무 없어서 당장은 제외"**를 달았다.

## 결정 사항

| 안건 | 결정 |
|---|---|
| 사진 업로드 방식 | **즉석 촬영과 갤러리 불러오기 모두 지원** |
| 하루 캔버스 룰 | 갤러리 진입 시 **'오늘 찍은 사진'이 디폴트 탭.** 전체 갤러리는 한 뎁스 안쪽. 하루 단위로 리셋되는 무드를 강제한다 |
| 동시 편집 충돌 | "겹치면 씹히고 좁아서 어렵다"는 우려를 반영해 **편집(크기·테두리 등)은 비공개 개인 화면에서 끝내고, 공유 캔버스에는 배치만** 한다 |
| 기능 선택과 집중 | 누끼 정확도 등 고도화된 편집은 1차 UT에서 덜어내고 **캔버스를 함께 채우는 공유 경험**에 집중 |
| 한 줄 정의 (확정 ✅) | **"파르페는 친구들과 공유 캔버스에 일상을 스티커로 만들어 붙이는 서비스다."** 보조 셋 — 매일 새 캔버스 / 일상 사진을 누끼 스티커로 / 친구 일상 위에 내 일상을 붙인다 |
| Is / Is Not (확정 ✅) | 아래 표 |
| 1차 UT 기능 범위 | **다음 회의로.** 1차 UT는 실제 개발이 아닌 목업(화면 이미지·피그마 프로토타입) |

한 줄 정의의 필수 키워드는 넷이다 — **그룹 / 동시성 / 하루 단위 / 캔버스(누적).**

### Is / Is Not

| 파르페는 ___ 이다 | 파르페는 ___ 이 아니다 |
|---|---|
| 사이버 다꾸 | 사진 편집 앱 |
| 같이 꾸미는 일상 캔버스 | 누끼만 따주는 앱 |
| | 셋로그 |
| | 예쁜 필터나 스티커 제공 앱 |
| | 사진 스타일 변환 앱 |
| | 공유 앨범 (같이 꾸미는 느낌 추가 필요) |
| | 일기 — 하루 정리가 아니라 하루 중 언제든 올리고 싶을 때 들어와 꾸미는 것 |

**"만들지 않는 것"이 제품 정체성 수준에서 적힌 첫 자리다**([[mvp-scope-limits]]).

## 범위·정책에 미친 영향

- **12명 상한에 근거가 붙는다** — 친밀한 폐쇄 그룹 가설. [[mvp-scope-limits]]
  표는 이 항목의 근거를 "없음"으로 적어 왔다([[group]]).
- **편집과 배치의 분리가 여기서 정해졌다** — 개인 화면에서 편집, 공유 캔버스에서
  배치. [[topping-placement-pipeline]]의 구조가 이 결정의 귀결이다.
- **갤러리 '오늘 사진' 디폴트**는 [[src-회의록-2026-05-28-회의]]에서 A안으로
  확정되고, [[src-회의록-2026-06-04-회의]]의 03시 경계와 묶여 `C-102`의 시간 창이
  된다([[canvas]]).
- 와이어프레임 역할 분담 — 메인 `DSN-B`, 사진 업로드·편집·배경 선택 `DSN-A`.
