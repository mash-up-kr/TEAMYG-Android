# 회의록 2026-10-04 텍스트 기능 정의 회의

## 요약

2026년 10월 4일 디자인 회의다. **캔버스에 사진이 아닌 텍스트를 올리는 기능**을
처음 정의했다. 질문을 다섯 묶음(입력/생성, 공동 캔버스, 스타일, 배치/조작,
운영/정책)과 기술/일정으로 나눠 하나씩 `최종결정`을 적었다.

**기본 원칙은 "사진과 동일하게"다.** 공동 캔버스 특화 항목과 배치/조작 항목을
원본이 각각 "여기까지 모두 사진과 동일하게", "이것도 사진이랑 다 동일하게"로
묶어 닫았다.

## 결정 사항

### 입력/생성

| 항목 | 결정 |
|---|---|
| 입력 방식 | **시스템 키보드** (커스텀 키보드 아님) |
| 글자수 | **띄어쓰기 포함 100자** |
| 줄바꿈 | 줄바꿈 1회 = 띄어쓰기 1회. 100자 안이면 별도 제한 없음 |
| 이모지 | 허용. 1개 = 1자 |
| 정렬 | 좌·중·우 커스텀 지향 ("가능했으면… 좋겠어요") |

### 공동 캔버스

- 수정은 **본인만**. 레이어는 **마지막에 쌓은 것이 맨 위**.
- 다른 사람 텍스트 위에 쌓기 허용. **텍스트 개수 제한 없음**(1인당·캔버스당 모두).

### 스타일 — 대부분 뺐다

| 항목 | 결정 |
|---|---|
| 그림자/효과, 투명도, 자간/행간, 굵기·기울임 | **전부 X** |
| 폰트 | 처음엔 "시스템 폰트 하나" → 같은 자리에서 **"시스템폰트 ㄴㄴ, 수트 다국어지원 / 라이선스 찾아보기"**로 뒤집힘 |
| 텍스트 배경 | **O.** "폰트에서 힘 빼고" 배경을 넣는다. 배경 테두리는 디자인 시도 후 안 되면 기각 |

### 배치/조작 — 사진 토핑과 같다

- 이동은 한 손가락. 크기·회전은 **캔버스 배치 시 두 손가락 핀치**. 작성 중에는
  크기를 조절하지 않는다.
- 캔버스 밖 이탈은 **지금처럼 클립**.

### 운영/정책 — 셋 다 불필요

- 비속어 필터링 **X**, 신고 기능 **X**, 접근성(대비·가독성 기준) **X**.
- 다국어: **한/영/일/중/숫자/이모지**.

### 기술/일정

- 저장 방식은 "이미지 합성 vs 텍스트 객체 유지" 중 **"업로드 후 수정 가능케 하려면
  후자"라는 줄이 취소선으로 지워지고 "수정 안되는 걸루"**로 적혔다. 저장 방식
  자체는 [[src-회의록-2026-10-06-회의]]에서 닫혔다.
- **첫 진입점: `Canvas-Menu` 2단 버튼을 3단으로 바꾼다.**
- 다음 회의: 와이어프레임 품평, 토요일 22시([[src-회의록-2026-10-10-디자인-회의]]).

## 범위·정책에 미친 영향

- **캔버스에 올라가는 것이 사진 토핑 하나에서 둘로 늘었다.** 지금까지
  [[topping-placement-pipeline]]은 "사진이 토핑이 되는 경로는 하나뿐"이었다.
  텍스트는 누끼를 거치지 않는 두 번째 경로이고, 진입점이 `Canvas-Menu` 2단에서
  3단으로 바뀐다([[canvas]]).
- **범위 밖으로 민 것과 근거.** 신고·필터링을 뺀 근거는 10-06 회의가 붙였다 —
  "사진도 신고 기능 없음", 접근성은 "친구끼리 놀 때 쓰는 용도". 스타일 다섯 항목은
  근거 없이 X다([[mvp-scope-limits]]).
- 100자 상한은 [[src-회의록-2026-11-03-회의]]에서 **500자**로 늘었다.
