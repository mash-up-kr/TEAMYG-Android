# 그룹명 정책 v0.1 (A-005)

## 요약

새 그룹 생성(`A-005`) 시 **그룹명 입력의 유효성 규칙**을 정한다. 2026년 7월 2일자
v0.1이고 작성자는 `DSN-A`다. 정책 이미지 1장에서 옮겼다(스크린샷 2026-07-13).

[[src-G-001-무한파르페-정책설계]]에 이은 **정책 설계서 계열 두 번째 문서**다.
기능정의서와 서로 대체하지 않는다 — 두 계열의 관계는 [[spec-version-history]]에
있다.

문서 자체가 `v0.1` 개정이력을 갖는다. 기능정의서 판본군과 별개의 번호 체계다.

## 규칙

| 항목 | 규칙 |
|---|---|
| 허용 문자 | 한글, 영문, 숫자, **공백**. 특수문자·이모지 불가 |
| 글자 수 | **최소 1자 ~ 최대 10자.** 글자 사이 공백도 1글자로 센다 |
| 공백 위치 | 맨 앞·맨 뒤 불가. 글자 사이는 **1칸만** 허용, 연속 공백 불가 |

통과: `홍 길동`(사이 공백 1칸). 불통과: `   `(공백만), ` 길동`·`길동 `(앞뒤 공백),
`홍  길동`(연속 공백 2칸), 10자 초과.

원본의 통과 예시 중 `열다섯글자열다섯글자`는 이름과 달리 실제로 10자다. 규칙
자체는 10자로 일관된다. **왜 이름이 어긋나는지는
[[src-S-002-앱닉네임-정책-v0.1]]을 ingest하며 밝혀졌다** — 아래를 본다.

## 이 문서는 닉네임 정책서의 사본이다

**규칙 본문의 제목은 "닉네임 생성 정책"인데 적용 범위(§3)는 "그룹명"이다.**
원본이 비고에서 이 어긋남을 스스로 밝히며 "닉네임 정책과 규칙 공유 가능성 있음"
이라고만 적었다.

같은 날 나온 [[src-S-002-앱닉네임-정책-v0.1]]이 답을 준다.

| | 앱 닉네임 정책서 | 이 문서 |
|---|---|---|
| 상한 | 15자 | 10자 |
| 통과 예시 | `열다섯글자` × 3 = **15자** | `열다섯글자` × 2 = 10자 |
| 규칙 본문 제목 | 닉네임 생성 정책 | **닉네임 생성 정책** |
| 작성자 | `DSN-B` | `DSN-A` |
| 날짜 | 2026-07-02 | 2026-07-02 |

**이 문서는 앱 닉네임 정책서를 복사해 만들었다.** 상한을 줄이며 예시 문자열의
토막을 하나 지웠는데 토막의 이름과 문서 제목은 그대로 남았다. "규칙 공유 가능성"
이라는 표현도 이것으로 설명된다.

**규칙 구조는 같고 상한만 다르다** — 그룹명 10자, 닉네임 15자.

[[src-S-102-닉네임-정책-v0.1]]이 이 관계를 직접 못박는다 — 연관 문서 항목에
"규칙 구조 동일, **글자수 상한만 다름 — 그룹명 10자 / 닉네임 15자**"라고 적혔다.
예시 문자열의 길이로 추론한 것이 원본으로 확인됐다.

## 기능정의서와의 관계

`A-005`의 그룹명 관련 서술은 기능정의서에도 있다.

| | 기능정의서 | 이 문서 |
|---|---|---|
| 분기조건 | 그룹명 입력 여부, **중복은 허용** | (다루지 않음) |
| 예외처리 | 그룹명 미입력, ~~금칙어~~ | 허용 문자·길이·공백 위반 |

어긋나지 않고 보완한다. 기능정의서가 "입력했는가 / 중복인가"를 보고 이 문서가
"무엇을 입력할 수 있는가"를 정한다.

**다만 금칙어가 사라졌다.** [[src-기능정의서-v4]]까지 `A-005` 예외처리에
"그룹명 미입력/금칙어"가 있었는데 [[src-기능정의서-v5]]에서 "그룹명 미입력/
네트워크 실패 시 재시도"로 바뀌며 금칙어가 빠졌다. **이 정책서에도 금칙어
규칙이 없다** — 허용 문자만 정한다. 답이 나온 적 없이 사라진 것으로 읽는다
([[purpose]]).

## 입력 한도와 표시 한도가 다르다

입력은 **최대 10자**인데 그룹 목록의 이름 칩은 **최대 6자**만 노출하고 7자
이상이면 앞 5자 + `…`으로 자른다([[infinite-parfait]]).

모순은 아니다. 다만 **7~10자 그룹명은 목록에서 항상 잘려 보인다.** 의도된
것인지 서술이 없다.

## 미결

- 금칙어 정책.
- 7~10자 그룹명이 목록에서 늘 잘리는 것이 의도인지.
- 그룹명 **중복은 허용**한다고 기능정의서가 적었으나 닉네임 중복은 어느 문서도
  다루지 않는다.

전부 [[open-questions]]에 있다.
