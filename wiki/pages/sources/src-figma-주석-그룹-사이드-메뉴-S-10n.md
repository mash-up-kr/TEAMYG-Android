# Figma 주석 — 그룹 사이드 메뉴 (S-10n)

## 요약

Figma `[디자인] 파르페 v0.1`의 `ㄴ 그룹 사이드 메뉴 (S-10n)` 페이지 스냅숏이다.
2026-11-13 수집. 카드 4장(메뉴 본체, 닉네임 수정, 그룹 나가기, 그룹 신고)이
전부 07-15~07-25, `DSN-B` 작성이다. **v7 이후 새로 그려진 카드가 없다.**

## 화면 ID — v7과 비교

| 구분 | ID |
|---|---|
| 양쪽에 있다 | `S-101`, `S-102`, `S-103`, `S-104`, `G-001` |
| v7에만 있다 | 없음 |
| 프레임에만 있다 | 없음 |

**v7의 그룹 사이드 메뉴 행과 프레임이 1:1로 맞는 유일한 페이지다.** v7이 적은
`S-103` 중복 명명 결함("기존에 프레임명을 S-103으로 잘못 설정")도 지금은 `S-103`
하나, `S-104` 하나로 정리돼 있다.

## 정책 문서에 없는 동작 주석

- **그룹 나가기(`S-103`)** — "그만두기"는 모달만 닫고, "나가기"는 **`G-001`로
  이동 + 나가기 확인 토스트 2초**.
- **그룹 신고(`S-104`)** — "신고하기"는 **`G-001`로 이동 + 신고 완료 토스트 2초.**
  v7 `S-104`는 "접수 안내 토스트 노출"만 적었고 **신고 뒤 그룹 목록으로 나간다는
  서술이 없다.** 신고가 그룹을 나가는 것까지 포함하는지는 이 주석으로도 알 수 없다.
- **닉네임 변경 시점(`S-102`)** — 키보드 엔터 또는 활성화된 확인 버튼. **확인
  버튼은 키보드가 올라와 있을 때만 노출**(v0.2 개정이력 "확인 버튼 추가").
- `S-101`은 "뎁스없음 / 내 프로필 눌러도 뎁스없음" — 프로필을 눌러도 하위 화면이
  없다.
- **탈퇴한 사용자는 "무조건 이름 알수없음"**. 이미 [[account]]가 인용하는 주석이다.

## 초대 문구 템플릿 — 브랜드 동사와 어긋난다

> 친구가 파르페에 초대했어요.
> 체리 올리러 가볼까요? [코드6자리]

- **초대 코드가 6자리**라는 것이 여기 있다.
- **"올리러"는 [[src-회의록-2026-09-29-회의]]가 `P-03`에서 QA 결함으로 고친 그
  동사다**("올리러 → 쌓으러"). 같은 템플릿이 캔버스 페이지에도 그대로 있다
  ([[src-figma-주석-캔버스-C-SY]]).
- [[src-회의록-2026-11-10-회의]]가 초대를 **복사에서 시스템 공유로** 바꿨으나 이
  페이지에는 공유 쪽 주석이 없다. 공유 동작은 캔버스 페이지에 있다.
