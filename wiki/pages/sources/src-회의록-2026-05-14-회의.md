# 5/14 회의록 (2026-05-14)

## 요약

전체회의다. Discord. 본문 일시는 **"2026년 5월 13일 (목) 21:30"**인데 5월
13일은 수요일이고 DB 날짜는 05-14(목)다 — 본문 날짜가 오기로 보인다. 안건은
설문 배포, **플로우차트 최종 결정**, 일정, 캔버스 크기다.

## 결정 사항

**설문 확정** — [[src-회의록-2026-05-09-작업데이]]의 12문항에서 두 곳이 바뀌었다.

- 소속 플랫폼에 **Web** 추가.
- 연령대를 **20~24 / 25~29 / 30~34세 셋**으로 좁혔다(10대·35세 이상 삭제).
  성별에서 "선택하지 않음" 삭제.

**플로우차트 수정 의견과 최종 확정**

| 항목 | 결정 |
|---|---|
| NavBar | **없음** |
| 푸시알림 목록 쌓아두기 | 우선순위 높지 않음 |
| 기본 닉네임 | **OAuth에서 이름을 가져올 수 있으면 이름, 안 되면 랜덤** |
| 그룹 이름 | **정하면 그룹 이름 & 인원 수 수정 안 됨** |
| 지난 캔버스 | 서버에 보관 |
| 캔버스 배경 | 따로 설정 가능. **단색 몇 개 지정, 스포이드는 MVP 제외** |
| **푸시알림** | **MVP에서 제외** — 아무도 안 올릴 때 / 너무 활발할 때 / 올리면서 찌르기 유도 |

**캔버스 크기** — **"인스타스토리 용 생각하면 세로"**, **태블릿 등은 MVP 외.**

**일정** — 기능명세서 5/14~5/21(데드라인 5/23 인터뷰 세션), 와이어프레임
~5/30, **MVP 개발 5/30~7/18.** 정기회의는 21:00로 당긴다. 서비스명은 5/23까지
전원이 정한다.

## 범위·정책에 미친 영향

**[[mvp-scope-limits]]의 오래된 항목 셋이 여기서 처음 정해졌다.**

- **그룹명·인원수 수정 불가** — 기능정의서 v2(05-30)의 "추후 변경 불가"보다
  2주 앞선다. 근거는 이 회의에도 없다([[group]]).
- **세로 모드 전용·태블릿 제외** — **근거가 적혔다: 인스타 스토리용.** 이 위키가
  [[src-C-001-캔버스-정책-v0.1]]에서 처음 본 "세로 모드 전용, 태블릿·가로모드
  미고려"의 근거가 이것이다([[canvas]]). 인스타 스토리는 세로 9:16이라 v7이
  "16:9"를 9:16으로 바로잡은 것과도 맞는다.
- **기본 닉네임 = 소셜 이름 또는 랜덤** — 기능정의서 `A-002`의 "계정 이름 받아와서
  회원가입/랜덤부여"의 출발점이다([[account]]).

**푸시가 MVP에서 빠졌다가 v7에서 들어왔다.** 이 회의는 푸시를 MVP 밖으로 밀었고
4/30도 "특정 시간 알림"을 배제했는데, [[src-기능정의서-v7]]이 푸시 3종을 신설했다
([[push-notification]]). 되돌린 근거는 이 범위의 소스에 없다.

**단색 배경은 "몇 개 지정"까지만 정해졌다** — 기능정의서가 v2부터 "단색 팔레트 색상
정의 필요"를 단 것과 이어진다.
