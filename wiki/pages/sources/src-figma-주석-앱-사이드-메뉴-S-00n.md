# Figma 주석 — 앱 사이드 메뉴 (S-00n)

## 요약

Figma `[디자인] 파르페 v0.1`의 `ㄴ 앱 사이드 메뉴 (S-00n)` 페이지 스냅숏이다.
2026-11-13 수집. 카드는 6장이고 작성자는 전부 `DSN-B`다. 07월 카드 넷(계정 정보,
서비스 탈퇴, 약관, 메뉴 본체)에 **10-31 카드 둘(알림 설정, 공지사항)**이 더해졌다.

**이 페이지에서 메뉴 구성이 바뀌고 있다** — 알림 설정·공지사항이 들어오면서
"앱 사이드 메뉴가 너무 많아져서 스크롤이 과해" 웹뷰 항목을 아래로 묶는 안이
제안돼 있다.

## 화면 ID — v7과 비교

| 구분 | ID |
|---|---|
| 양쪽에 있다 | `S-001`, `S-002`, `S-003` |
| **v7에만 있다** | `S-004`, `S-005` |
| **프레임에만 있다** | **`S-105`**, `S-105-OS-Off`, `S-105-Save-Fail`, **`S-106`**, `S-106-Detail`, `S-106-Error`, **`S-001-Android`**, `(구버전)S-001`, `A-002-1` |

- **`S-105`(알림 설정)와 `S-106`(공지사항)이 v7 뒤에 생긴 ID다.** 둘 다 앱 메뉴인데
  `S-10x` 대역을 받았다 — v7까지 `S-1xx`는 그룹 사이드 메뉴(`S-101`~`S-104`)였다.
  **번호 대역이 메뉴 층위를 가리키던 규칙이 여기서 깨진다**([[screen-id-scheme]]).
  정책은 [[src-푸시알림-인앱-알림-제어-정책-v0.3]]과
  [[src-S-106-공지사항-운영-정책-v0.3]]에 있다.
- **`S-004`는 화면이 아니다.** 약관 카드 옆에 **"웹뷰로 띄움 (화면 X)"**이 적혀
  있고 `S-004` 프레임이 없다. v7은 `S-004` 기타에 "약관과 개인정보 처리방침이 별도
  화면으로 분리됨 — 프레임 S-004(약관) / S-004(개인정보…)"라 적었다. 웹뷰라는 결정
  자체는 v4부터 같다.
- `S-005`(로그아웃)도 프레임이 없다. v7이 "전용 프레임 없음"이라 적은 것과 맞는다.
- **`S-001-Android`** — "아동 안전 정책 추가한 버전". 메뉴에 **아동 안전 정책
  (안드만)** 웹뷰 항목이 붙은 Android 전용 변형이다. 근거는
  [[src-회의록-2026-10-06-회의]]의 CSAE 대응(플레이스토어 카테고리 소셜 전환)이다.
  **사이드 메뉴 구성이 플랫폼별로 갈린 첫 사례다.**

## 정책 문서에 없는 동작 주석

- **메뉴 재배치 제안** — 웹뷰 항목 넷(이용약관, 개인정보처리방침, 오픈소스 라이선스,
  아동 안전 정책(안드만))을 아래로 묶어 작게 보여주고, `Profile-Card`와
  `List-Container`를 Gap 16으로 묶는다. **"별로면 지금 가리키고 있는 버전으로
  개발"**이라 적혀 있어 확정이 아니다. **오픈소스 라이선스 항목은 v7에 없다.**
- **NEW 칩** — 라벨 오른쪽, 동시에 최대 2개(보통 1개), `S-001`과 위치 통일, 제목이
  두 줄을 넘으면 칩 자리를 남기고 말줄임. 정책서의 "제목 뒤 `Chip-New`"와 맞는다.
- **약관 개정 공지 제목** — 이용약관만 개정되면 "이용약관 개정 안내", 둘 다면
  "이용약관 및 개인정보처리방침 개정 안내". 공지사항 정책서와 같다.
- **알림 설정** — 기기 알림이 꺼져 있으면 토글이 비활성화되고, **꺼지기 전 설정값
  그대로 Disabled**로 보인다. 설정에서 켜야 `S-105`로 돌아온다. **저장 실패 시
  토스트, "페이지 재진입으로 리프레시"**. 정책서는 저장 실패 시 **"바꾸기 전으로
  되돌리고 토스트"**라 적어 복구 방식이 다르게 읽힌다.
- **탈퇴(`S-003`)** — 완료 후 `A-002-1`로 이동, **탈퇴 완료 토스트 2초**. v7 `S-003`
  시스템 동작은 "앱 종료", 다음 단계는 `A-001`이다.
- 앱 닉네임을 다 지우고 엔터를 누르면 "닉네임은 비워둘 수 없어요".
