# 그룹 토핑 템플릿 정책 v0.2 (G-001)

## 요약

`v0.1` 다음 날인 2026년 7월 26일자 `v0.2`다. 작성자는 `DSN-B`로 같다.
[[src-G-001-그룹-토핑-템플릿-정책-v0.1]]을 대체한다.

**개정이력은 "빈 캔버스 템플릿 및 에러 템플릿 이미지 추가" 하나만 적는다.**
그런데 **실제로는 템플릿 6종의 정체가 통째로 바뀌었다.**

## 디저트가 아니게 됐다

| | `v0.1`(07-25) | 이 문서(07-26) |
|---|---|---|
| 템플릿 6종 | **딸기 / 키위 / 오레오 / 딸기과자 / 파랑젤리 / 노랑젤리** | **별 둘 / 음표 둘 / 소용돌이 둘** |
| 스타일 | (없음) | **회색 계열 반투명 아웃라인** |
| 조회 실패 | 물음표 모양 **과자** 형태 | 물음표 모양 형태 |

**하루 만에 뒤집혔고 폐기 선언이 없다.** 본문의 "템플릿 종류"가
`딸기, 키위, …` 목록에서 **"총 6종, 하단 참고"**로 바뀌었을 뿐이다. 조회 실패
쪽은 **"과자"라는 단어만 빠졌다.**

**개정이력이 "추가"라 적었는데 실제로는 교체다.** 이 계열에서 폐기를 폐기라고
적어 온 전례(구 clip OFF 정책, 문자수 기준, 그룹 ID 시드)와 다르다
([[spec-version-history]]).

**디저트 은유가 빈 상태와 에러에서 물러섰다.** [[parfait]]의 은유가 화면 구조와
팔레트를 지나 빈 상태 그래픽까지 내려왔던 것이 **하루 만에 되돌아갔다.** 토핑이
실제로 올라온 자리만 디저트로 남는다.

> ⚠️ [2026-09-17] [[src-G-001-무한파르페-정책설계-v0.3]] 와 상충 — 그쪽은
> 템플릿 6종을 여전히 **딸기 / 키위 / 오레오 / 딸기과자 / 파랑젤리 / 노랑젤리**로
> 적는다. 어느 쪽도 다른 쪽을 대체한다고 선언하지 않았다 → [[open-questions]]

## 에셋 시트

![그룹 토핑 템플릿 그래픽 시트와 적용 예시](../../raw/assets/G-001-그룹-토핑-템플릿-v0.2-그래픽시트.png)

| 에셋명 | 형태 |
|---|---|
| `Template01` | 별 (도트 무늬) |
| `Template02` | 별 (격자 무늬) |
| `Template03` | 음표 (8분음표) |
| `Template04` | 음표 (쌍음표) |
| `Template05` | 소용돌이 (가는 선) |
| `Template06` | 소용돌이 (굵은 선) |
| `Template-E…` (Error) | 물음표 |

**셋이 짝을 이룬다** — 별·음표·소용돌이가 각각 무늬나 굵기만 다른 둘이다. 6종이
여섯 가지가 아니라 **세 가지의 변주 둘씩**이다.

**에러 그래픽이 같은 시트에 들어 있다.** 이름이 `Template-E…`라 템플릿 번호
축과 같은 계열로 관리되는데, **본문은 여전히 조회 실패와 빈 템플릿을 다른
절에서 다룬다.**

## 규칙이 하나 명시됐다

**"템플릿 그래픽도 일반 토핑과 동일하게 지그재그 배치·그룹 칩 노출 규칙을
따른다."**

처음 적혔다. `v0.1`은 무엇을 노출하는지만 정하고 배치는 다루지 않았다. 빈
그룹도 [[infinite-parfait]]의 지그재그와 좌표를 그대로 쓰고 **그룹 칩도 뜬다** —
`v0.1`이 조회 실패에만 적었던 "그룹 칩은 정상 노출"이 빈 템플릿에도 걸린다.

## 목업에서만 보이는 것

우측 "템플릿 적용 예시"는 `G-001` 화면 목업이다. **본문이 서술하지 않은 것이
여럿 보인다.** 목업은 치수도 주석도 없으므로 아래는 **본문 서술이 아니라 관찰**
이다.

- **토핑 7개가 지그재그로 얹혀 있고 `index 0`이 `Left`다.** 정책설계 `v0.2`가
  고른 시작 사이드와 맞는다.
- **템플릿 여섯과 에러 하나가 한 화면에 섞여 있다.** 실제로는 모두 빈 그룹이거나
  조회 실패인 상태라 정상 토핑이 하나도 없는 화면이다.
- **그룹 칩이 전부 떠 있고 Timestamp 컬러가 넷 보인다** — 초록·회색·노랑·분홍.
  [[src-S-101-프로필-이미지-및-그룹칩-내-타임스탬프-컬러-규칙-v0.1]]의 매핑과
  결이 같다.
- **칩이 각 토핑 아래에 붙는다.** 이 위키는 `Chip`이 **우측 하단**에 붙는다고
  적어 왔는데, 목업만으로 기준점을 판정할 수 없다 — `Chip` 배치 기준점은 두
  계열 모두 아직 미정이다([[open-questions]]).
- **상단에 `+ 그룹 추가하기` 버튼이 있다.** 그룹 생성 진입이 `G-001` 상단바에
  있다는 첫 시각 증거다([[open-questions]]).
- **`December 31 (Wed)` 날짜 라벨이 있다.** [[canvas]]의 `Button-Date-Select`와
  같은 꼴(`May 20 (Wed)`)인데 그것은 `C-001`의 요소다.
- **배경이 격자다.** `Background-Dot-Grid` 역시 [[src-C-001-캔버스-정책-v0.2]]가
  `C-001`에 둔 것이다.
- 체리는 빨강 단색이고 크림·잔은 흰 아웃라인이다. 체리의 기능은 여전히 `TBD`다.

**뒤의 셋은 `C-001`의 요소가 `G-001` 목업에 나타난 것이다.** 목업이 공용
프레임을 쓴 것인지 `G-001`이 실제로 그 요소들을 갖는 것인지 본문에 없다
([[open-questions]]).

## 메타데이터

- **날짜가 `26.07.26`이다.** `v0.1`의 `26.07.25` 바로 다음 날이고 **세 번째 축약
  표기**다. 셋 다 `DSN-B`가 썼다.
- **출처 줄도 참고 줄도 없다.** `v0.1`과 같다. `DSN-B`의 문서 셋이 연속으로
  캡처 정보를 달지 않았다.
- **개정이력이 두 줄로 늘었다** — `v0.1` 초안, `v0.2` 이미지 추가. 이 계열에서
  개정이력이 누적 표기된 첫 문서인데, **적힌 변경과 실제 변경이 어긋난다.**
- 개정이력이 **"빈 캔버스 템플릿"**이라 적는다. 본문과 다른 문서는 전부 **"토핑
  템플릿"**이다. `캔버스`는 [[canvas]]의 이름이라 다른 것을 가리킨다.

## 그대로인 것

- 조회 실패 시 **그룹 칩 정상 노출**, 실패 그래픽 **1종**.
- 6종 중 **1종 랜덤 최초 부여**, **첫 토핑 등록 전까지 고정**, 새로고침·재접속·
  타 그룹 갱신에도 **불변**.
- 저장 위치와 "첫 토핑 이후"는 여전히 없다([[open-questions]]).

## 미결

- 템플릿 6종의 정체가 [[src-G-001-무한파르페-정책설계-v0.3]]과 어긋난다.
- 개정이력이 "이미지 추가"라 적었는데 실제로는 6종 교체다.
- `C-001`의 날짜 라벨·격자 배경이 `G-001` 목업에 나타난 이유가 없다.
- `+ 그룹 추가하기`가 어느 화면으로 가는지 없다.
- 부여된 템플릿의 저장 위치, 첫 토핑 이후의 거동이 `v0.1`에서 그대로 열려 있다.
- 날짜 표기가 축약형이고 출처·참고 줄이 없다.

전부 [[open-questions]]에 있다.
