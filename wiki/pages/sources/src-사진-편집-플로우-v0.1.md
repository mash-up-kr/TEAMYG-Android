# 사진 편집 플로우 v0.1 (C-105-Arrange / C-105)

## 요약

**이미 쌓은 본인 사진을 고치는 흐름**을 정한다. 카드 일자 **26.09.25**, `v0.1`
초안, 작성자 `DSN-B`다. 카드 대상은 "`C-001`에서 내 토핑 탭 / `C-105-Arrange`에서
사진 or ▲ 아이콘 터치 / `C-105`"다. Figma 캔버스 페이지에서 옮겼다.

[[src-토핑-쌓기-플로우-개선-2-변경-사항-2026-09-22]]의 개편을 **수정 경로에
적용한 문서**다. 원본이 그 개편의 헤더 규칙을 **"v2 헤더 규칙"**이라 부른다.

## 구조 — 배치와 테두리를 한 화면으로

- **배치(`C-105-Arrange`)와 테두리(`C-105`)를 한 화면으로 합친다.** 둘 사이는
  페이지 이동이 아니라 **같은 화면의 상태 전환**이다. 뎁스가 하나 준다.
- **수정 흐름에는 영역 수정(`C-104`)이 없다.** 영역 수정은 최초 업로드 때만이다.

## 진입과 헤더

| 무엇을 탭 | 결과 |
|---|---|
| `C-001`에서 **본인 사진** | `C-105-Arrange` 진입 |
| `C-001`에서 **남의 사진** | 토스트 `XX님이 N분 전에 쌓았어요` (기존 유지) |

헤더는 **`X`만** 있다 — 수정 흐름은 이전 단계가 없어 `<`를 두지 않는다. `X`는
`C-001`로 가고, 변경이 있으면 확인 팝업을 1회 띄운다.

## `C-105-Arrange` — 패널이 닫힌 상태

### 사진 상태 3종

| 사진 | 상태 |
|---|---|
| 진입할 때 탭한 본인 사진 | **포커스** — 점선 선택 박스 + 삭제(`X`) 아이콘 |
| 본인의 나머지 사진 | **활성** |
| 남이 올린 사진 | **딤** |

### 탭과 조작

- 포커스된 사진을 **한 번 더 탭** → `C-105`로 전환, 테두리 패널이 열린다.
- 활성인 본인의 다른 사진 탭 → 포커스가 그 사진으로 옮겨 간다.
- 딤 처리된 남의 사진 탭 → 편집되지 않고 토스트 **`다른 사람의 사진은 편집할 수
  없어요`**.
- 이동은 드래그, **회전·확대는 두 손가락 핀치**(아이콘 삭제), 삭제는 모서리
  아이콘 유지.
- **편집(연필) 아이콘을 지웠다** — 근거: "터치 영역이 작아 잘 안 눌림".
- 하단은 접힌 `테두리 설정` 바(▲)와 `[캔버스에 쌓기]` CTA.

## `C-105` — 테두리 패널이 열린 상태

- 진입: 포커스된 사진 재탭, 또는 `테두리 설정` 바의 ▲.
- 항목: **테두리 굵기(슬라이더)**, **테두리 색(없음 + 컬러칩 가로 스크롤)**.
- **패널이 열리면 편집 중인 사진이 화면 가운데로 자동 이동한다** — 원본이 든
  비유는 "인스타그램 스토리 텍스트 수정과 동일".
- 패널 밖 캔버스 탭이나 ▼ → 패널이 닫히고 사진이 원래 위치로 돌아간다.
- **패널이 열린 동안은 무엇을 탭하든 패널만 닫힌다.** 이동·포커스 전환·토스트가
  일어나지 않는다. 닫힌 뒤에 다시 조작해야 동작한다.

## 완료

`[캔버스에 쌓기]` → 위치·크기·회전·테두리를 현재 상태로 갱신하고 `C-001`로 간다.
패널이 열린 상태에서 눌러도 같다. **위치는 원래 위치 기준으로 저장한다** —
가운데 이동은 편집용 임시 위치다.

## 기존 위키와 어긋나는 것

> ⚠️ [2026-11-13] [[src-C-202-토핑-편집자-확인-규칙-v0.1]] 와 상충 — 본인 토핑을
> 탭했을 때 그쪽(및 [[src-기능정의서-v7]])은 **`C-305` 토핑 편집**, 이 문서는
> **`C-105-Arrange`**로 간다 → [[open-questions]]

- **추후 수정 경로가 통째로 바뀐다.** [[topping-placement-pipeline]]의 추후 수정은
  v7 기준 `C-304`(토핑 탭) → `C-305` 편집 → `C-306` 테두리였다. 이 문서는 **최초
  배치와 같은 `C-105-Arrange`/`C-105` 화면을 수정에도 쓴다.** `C-305`·`C-306`이
  폐기됐다는 선언은 없다.
- **남의 사진 탭이 Spotlight를 언급하지 않는다.** v7과 C-202는 타인 토핑 탭을
  Spotlight + 작성자 토스트로 적었다. 이 문서는 토스트만 적고 "기존 유지"라 한다
  — Spotlight가 유지되는지는 이 문서로 판정되지 않는다.
- **새 토스트 문구가 생겼다** — `다른 사람의 사진은 편집할 수 없어요`(편집 화면
  안에서 남의 사진 탭). [[src-Toast-공통-정책]]의 `내 토핑만 편집할 수 있어요`와
  같은 상황을 다른 문구로 적는다([[toast]]).
- **화면 ID가 또 움직였다.** v7의 `C-105`는 테두리 편집 화면, `C-106`은 캔버스에
  배치였다. 이 문서에서 배치는 `C-105-Arrange`이고 `C-105`는 그 화면의 패널 상태다
  ([[screen-id-scheme]]).
