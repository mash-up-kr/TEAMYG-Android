# 기능정의서_MVP v3 (2026-06-07)

> 이 판본은 [[src-기능정의서-v4]](2026-06-14)로 대체됐고, v4는 다시
> [[src-기능정의서-v5]](2026-06-25)로 대체됐다. **현행 사실은 v5에서 확인한다.**
> 판본 이력은 [[spec-version-history]]에 있다.

## 요약

parfait MVP의 화면 단위 기능정의서 3차 판본이다. 2026년 6월 7일자이며,
[[src-기능정의서-v2]]를 8일 만에 전면 대체한다. v2와 마찬가지로 Notion 페이지
캡처 2장에서 옮겼고 원본 페이지는 게스트 권한이라 접근하지 못했다.

화면 33건을 표 하나로 정의한다. 열 구성과 화면 ID 접두사 체계는 v2와 같다
([[screen-id-scheme]]).

**전면 대체로 판정한 근거**: v3가 MVP 화면 전체를 다시 정의하고, 원본 스스로
"v2 대비 주요 변경"을 페이지 비고에 적어 두 판본의 관계를 밝혔다. 범위 일부만
갱신한 것이 아니므로 `partial`이 아니라 `superseded`다.

## 핵심 주장

v2에서 바뀐 것만 적는다. 바뀌지 않은 것은 [[src-기능정의서-v2]]에 있다.

- **편집 진입 허브 `C-002`가 사라졌다.** v2에서 여섯 화면이 진입 경로로
  참조하면서도 정의되지 않았던 그 화면이다. v3는 `C-101`·`C-102`를 `C-001`에서
  직접 진입시키고, 배경·사진 편집은 `C-301`로 모은다.
- **`C-301`이 "캔버스 배경 변경"에서 "파르페 편집 모드 진입"으로 개편됐다.**
  배경 변경과 누끼 사진 편집의 공통 진입점이 됐다.
- **`C-305`·`C-306`이 신설됐다.** 누끼 사진 편집(삭제·각도·크기·위치)과 테두리
  편집이 각각 별도 화면이 됐다. v2의 `C-107`(사진 삭제)과 `C-108`(사진 위치
  수정)이 `C-305`로 흡수됐다.
- **사진의 최초 배치와 추후 수정이 경로상 분리됐다.** 최초는
  `C-101`~`C-106`, 이후 수정은 `C-301` → `C-305`/`C-306`이다. 흐름은
  [[topping-placement-pipeline]]에 있다.
- **그룹장 기능이 삭제됐다.** 페이지 비고에 명시돼 있고, `S-103`의 "그룹장 권한
  이양" 예외처리도 함께 빠졌다.
- **그룹명·인원수 수정 기능이 삭제됐다.** v2에서 "추후 변경 불가"였던 것이
  기능 삭제로 확정됐다. [[mvp-scope-limits]]에 있다.

판본 간 변경의 전체 분석은 [[spec-version-history]]에 있다.

## v4가 바꾼 것

- 캔버스 위의 객체 이름이 **"토핑"**으로 정해졌다. `C-305`·`C-306` 화면명이
  바뀌었다.
- 하루의 경계가 **00시에서 03시로** 옮겨졌다(`SY-001`, `SY-003`, `C-102`).
- 그룹 가입 시점에 **그룹 내 닉네임을 입력받는다**(`A-004`, `A-005`).
- 약관 화면이 **노션 웹뷰로 확정**됐다(`S-004`).
- `S-103`의 그룹장 관련 서술이 비워졌다. 다만 `A-005`의 "사용자 그룹장 등록"은
  v4에도 남아 아래 내부 모순이 완전히 풀리지 않았다.

## 번호 재사용

`C-305`가 두 판본에서 서로 다른 화면을 가리킨다 — v2에서는 "수정 완료"(배경 저장
확정), v3에서는 "누끼 사진 편집"이다. [[purpose]]가 경고한 번호 재사용의 실제
사례다. `C-305`를 언급할 때는 판본을 함께 적는다.

## 내부 모순

페이지 비고는 그룹장 기능 삭제를 명시하는데, 표는 그룹장을 남겨 뒀다.

> ⚠️ [2026-09-17] [[group]] 와 상충 — v3 페이지 비고는 "그룹장 기능 삭제"라고
> 적었으나 같은 문서의 `A-005` 시스템 동작은 "사용자 그룹장 등록"을, `S-103`
> 분기조건은 "그룹장 + 잔여 멤버 있음"을 그대로 남겼다 → [[open-questions]]

## 여전히 비어 있는 것

v2가 "정의 필요"로 남긴 정책은 대부분 그대로다 — 실시간 반영 방식, 누끼 처리
위치, 충돌 정책, 초대 코드 형식, 닉네임 정책, 조회 가능 기간, 최소 지원 OS,
탈퇴 데이터 보존. 대상 사용자 정의도 여전히 없다.

`C-304`(배경 색 설정)와 `S-005`(로그아웃)는 진입 경로와 다음 단계만 채워졌고
사용자 액션·시스템 동작 열은 비어 있다. 빈 칸은 "미정"으로 읽는다([[purpose]]).
