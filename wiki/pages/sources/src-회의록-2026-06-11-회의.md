# 6/11 전체회의 — 용어 통일, 나가기·탈퇴, 와이어프레임

## 요약

2026-06-11 21:00 Discord 전체회의. 기능정의서 수정(용어 통일, v3 현행화, 나가기·
탈퇴 정책)과 와이어프레임 리뷰가 본론이다. 작업 모임·티셔츠는 운영이라 뺀다.

## 결정 사항

### 용어 통일 — "이제부터 어기는 사람 꿀밤"

같은 것을 쌓기·사진 추가, 스트로크·아웃라인으로 제각각 부르던 것을 하나로 묶었다.

| 구분 | 대상 | 명칭 |
|---|---|---|
| 모드 | 구경 상태 | **파르페 모드** |
| | 활성 상태 | **에딧 모드** |
| 객체 | 누끼·손질 전 원물 | **원본 사진** |
| | 누끼 딴 사진 (+ 테두리 추가된 것) | **토핑** — '누끼'는 기능명으로만 남긴다 |
| 행동 | 초기 배치 | **배치** |
| | 스트로크·아웃라인·윤곽선 | **테두리** |
| | 대상 삭제 | **토핑 삭제** |
| | 에딧 모드에서 하는 모든 변경 | **에딧** |
| 나머지 | — | **캔버스 / 그룹 / 그룹원** |
| | `G-001` 밑에 깔리는 기본 배경 그래픽 | **템플릿** |

### 기능정의서 v3 현행화

원본이 v3의 변경을 셋으로 적었다 — **사진 초기 배치 / 추후 수정 분기**,
**그룹명·인원수 수정 기능 삭제**, **그룹장 기능 삭제**(둘 다 "MVP 제외인데 계속
있길래"). 그리고 위 용어로 텍스트만 한 번 더 고친다고 예고했다.

### 그룹 나가기·서비스 탈퇴

- **공통**: 그룹을 나가거나 탈퇴해도 캔버스에 올린 사진이 자동으로 삭제되지
  않는다는 것을 **약관에 명시**한다.
- **그룹 나가기**: 남은 토핑은 두고 **닉네임을 익명화**한다.
- **탈퇴**: **가입한 모든 그룹에서 자동 퇴장.** 남은 토핑은 두고 닉네임 익명화.
  **재가입은 바로 가능하고 신규 유저로 취급**한다.
- 후속 할 일란 — 개인정보 처리방침을 찾아본 뒤 **"최소 약관 확정 및 탈퇴 시
  닉네임 익명화로 결정"** ✅.

## 범위·정책에 미친 영향

- **v4의 "토핑" 명명이 여기서 나왔다.** [[src-기능정의서-v4]](06-14)가 캔버스 위
  객체를 토핑으로 부르기 시작한 것은 사흘 전 이 회의의 결정이다
  ([[spec-version-history]]). 같은 표가 **파르페 모드 / 에딧 모드**와 **템플릿**의
  뜻도 정했다([[infinite-parfait]]).
- **나가기·탈퇴 시 토핑 익명화 보존**은 [[src-기능정의서-v7]]이 `S-103`·`S-003`에
  적기 넉 달 전 결정이다. 근거는 원본에 없고 "약관 명시"라는 처리 방식만 있다
  ([[group]], [[account]]).
- **가로모드 불가**가 캔버스 정책서(07-09)보다 한 달 먼저 나왔다. 여기도 근거는
  없다([[mvp-scope-limits]]).
- **`C-104` 수동 편집은 "복원·삭제" 둘 다로 시작했다.** 뒤의
  [[src-C-104-누끼-편집-정책-v0.1]]은 되살리는 쪽만 적는다
  ([[topping-placement-pipeline]]).
- `C-202` 닉네임 노출은 1.5~2초 뒤 사라지는 일시 표시였다 — 뒤의 Spotlight 규칙과
  모양이 다르다([[canvas]]).
- `SY-001-new`의 "어제 캔버스 완성" 안내는 모달로 시작했고
  [[src-회의록-2026-07-09-회의]]에서 다시 다뤄진다.
