# 5/21 전체회의

## 요약

2026-05-21(목) 21:00 Discord 전체회의. 안건은 서비스명 정하기, **1차 기능명세서
확인**, 인터뷰 질문 선정, 인터뷰 세션 발표 자료, 파트별 할 일 점검이다.

원본은 두 층이다 — 회의 본문(사람이 적은 안건 메모)과, 녹음을 자동 요약한
"알트 요약" 하위 페이지. **두 층이 같은 안건에서 반대 결론을 적은 자리가 하나
있다**(아래 `C-106`).

**기능정의서의 1차 판본이 이 시점에 있었다.** 회의가 확인한 것은
`기능정의서_MVP.csv`이고, 수정 반영은 "인터뷰 세션 이후"로 미뤘다. 이 위키가 가진
가장 오래된 판본은 [[src-기능정의서-v2]](05-30)다 — v1은 raw에 없다.

## 결정 사항

| 안건 | 결정 |
|---|---|
| 1차 기능명세서 — `C-106` 수정 가능 여부 | 회의 본문: **"수정 가능하도록!"** — "위치 변경은 MVP에서 빼기엔 핵심기능" |
| 카메라 디자인 | **디자인 시안이 먼저 나온 뒤 공수 확인(2순위).** 디자인이 원하는 바를 대략 정해 공유해야 기술 검토가 편하다 |
| 서비스명 | 후보를 단톡방에 올려 투표로 정한다. 확정은 [[src-회의록-2026-05-28-회의]] |
| 인터뷰 질문 | 기존 질문을 검토해 필요 시 소폭 수정 |

### `C-106`을 두고 두 층이 어긋난다

알트 요약은 "MVP 기능 범위"로 **"사진 업로드 후 위치 고정(수정 금지)"**, "다중
선택이 아닌 한 대상을 선택", "좌표 정보만 서버에 저장"을 적었다. 회의 본문은
같은 안건에서 "수정 불가하게 가는 게 괜찮은가(수정 시 할 일이 너무 많아질 것
같다)"를 묻고 **굵게 "수정 가능하도록!"**으로 닫았다.

**회의 본문을 따른다.** 자동 요약은 논의 중 나온 안을 결정으로 옮겼을 수 있다.
뒤의 흐름도 본문 쪽이다 — [[src-기능정의서-v3]](06-07)이 **초기 배치와 추후
수정을 분기**했다([[src-회의록-2026-06-11-회의]]가 그 변경을 적었다).

알트 요약의 "카메라 버튼 3개 이하", "다중 사진 선택은 MVP 이후"도 회의 본문에는
없다. 자동 요약에만 있는 서술로 둔다.

## 범위·정책에 미친 영향

- **토핑 위치 수정이 MVP 핵심 기능으로 남았다** — [[topping-placement-pipeline]]의
  최초 배치 / 추후 수정 분기의 출발점이다.
- 카메라(`C-101`)는 디자인 선행, 개발 공수 판단은 그 뒤.
- 기능정의서 v1 → v2 사이에 인터뷰 세션([[src-회의록-2026-05-23-인터뷰-세션]])이
  끼어 있다. v2가 인터뷰 결과를 반영한 판본이라는 것은
  [[src-회의록-2026-05-28-회의]]의 "기능명세서 ver1 수정 — 인터뷰 세션 이후 기획
  반영 ✅"이 확인한다([[spec-version-history]]).
