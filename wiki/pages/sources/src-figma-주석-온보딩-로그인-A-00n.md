# Figma 주석 — 온보딩·로그인 (A-00n)

## 요약

Figma `[디자인] 파르페 v0.1`의 `ㄴ 온보딩 - 로그인 (A-00n)` 페이지에서 화면 정의
카드·참고사항·입력 필드 주석·프레임 이름을 옮긴 스냅숏이다. 2026-11-13에
브라우저 보기 전용 화면에서 수집했다. **판본이 매겨진 정책 문서가 아니라 디자인
파일의 현재 상태다.**

화면 정의 카드는 10장이고 날짜가 07-26~08-17에 몰려 있다. `DSN-A`가 대부분을
썼다. **[[src-기능정의서-v7]](09-21)보다 앞선 카드들이라 v7이 이 페이지를 받아
적은 쪽이다.**

## 화면 ID — v7과 비교

이 페이지 프레임에 있는 ID와 [[src-기능정의서-v7]]의 54건을 맞대면 이렇다.

| 구분 | ID |
|---|---|
| 양쪽에 있다 | `A-001`, `A-003`, `A-004`, `A-005` |
| **v7에만 있다** | **`A-006`**, `A-002`(접미사 없는 형태) |
| **프레임에만 있다** | `A-002-1`, `A-002-2 (수정 예정)`, `A-002-3 (수정 예정)`, `A-004-Default`, `A-004-naming`, `A-004-Confirm`, `A-004-이미 참여한 그룹 경고`, `A-004-유효하지 않은 초대코드`, `A-004-최대 인원 경고`, `A-005-Confirm`, `Redirect`, `Loading`·`Loading_Ex`, `Error` |

- **`A-006`은 Figma에 그 이름으로 없다.** v7은 `A-006`을 "피그마 `A-004-naming`을
  별도 페이지로 분리한 것"이라 적었는데, 이 페이지의 프레임은 여전히
  `A-004-naming`이고 카드 제목도 "그룹 참여 [기존] / 닉네임 설정"이다. **ID를 새로
  붙인 것은 기능정의서 쪽뿐이다**([[screen-id-scheme]]).
- `A-004`의 세 경고 상태는 각자 프레임이 있다. v7은 이것들을 "Code-Container 에러
  상태로 처리(별도 페이지 아님)"라 적었다 — 프레임이 따로 있다는 것과 어긋나지
  않는다. 상태를 그린 프레임일 뿐이다.
- `A-002-1`만 수정 표시가 없고 2·3은 **"(수정 예정)"**이다. v7이 페이지가 아니라
  했던 `A-002-1`~`3`([[open-questions]])이 Figma에서는 프레임 이름으로 남아 있다.
- 카드 **"브라우저 이동 / 외부"**(08-17, `DSN-A`)와 `Redirect` 프레임이 있다.
  무엇을 하는 화면인지 주석이 없다. v7 어느 행에도 대응하는 것이 없다.
- 카드 **"진입 경로 선택 / G-001로 이동"**(`DSN-B`)이 있다. v7이 정리한 대로
  `A-003` 다음이 `G-001`이고 그룹 참여·생성은 거기서 시작한다는 흐름과 맞는다
  ([[group]]).

## 정책 문서에 없는 동작 주석

- **에러 해제 조건** — "에러 뜬 후 문자를 입력하거나 삭제하면 에러 상태가 풀리도록"
  (두 곳). 입력 유효성 규칙을 다룬 정책서들은 에러를 **언제 띄우는지**만 적었고
  **언제 거두는지**는 없었다.
- `A-004` 오류 상태에서 입력 필드를 다시 누르면 **`A-004-Default`로 돌아간다.**
- 닉네임 입력 화면은 **진입 후 키보드 활성화 유지**.
- `A-003`의 약관 링크는 **`S-004`로 이동**한다.
- 닉네임 두 층의 호칭을 정한 메모가 있다 — "앱 닉네임 / 그룹 내 닉네임 … 이렇게
  분류합시다". [[account]]가 쓰는 두 이름이 여기서 나왔다.

입력 필드 주석의 에러 문구(허용 문자·앞뒤 공백·연속 공백, 빈 값 안내)는 기존
닉네임·그룹명 정책서와 같다. 길이 상한 문구는 이 페이지에 없다.
