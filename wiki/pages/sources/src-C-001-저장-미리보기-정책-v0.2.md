# 저장 미리보기 정책 v0.2 (C-001-Save-Preview)

## 요약

캔버스를 갤러리에 저장하기 직전에 **실제로 저장될 이미지를 먼저 보여주는 화면**의
정책이다. 문서 날짜 **2026-09-18**, 상태 표기 **"🟢 최종안 확정 (일부 미결
잔존)"**, 노션 최종 편집 09-20(`DSN-B`). 출처는 Figma `C-001-Save-Preview`
프레임이다.

**이 문서가 화면 ID `C-001-Save-Preview`를 새로 부여했다.** 진입은 `C-001` 날짜바의
저장 아이콘([[src-C-001-캔버스-정책-v0.3]])이다.

원본 첫머리가 스스로를 **복제본**이라 밝힌다 — 원본 `v0.1`은 그대로 두고 Figma
최종안 기준으로 고친 버전이다. **`v0.1`은 `wiki/raw/`에 들어온 적이 없다.** 그래서
이 페이지는 대체할 대상이 없고, `v0.1`의 내용은 아래 §5 비교표로만 읽힌다.

지금까지 이 문서는 [[src-기능정의서-v7]]의 `기타` 열 전재로만 읽을 수 있었다.

## 왜 만들었나 — UT 발견

저장(내보내기)하면 **인스타 스토리 바이럴용 9:16 이미지 1장**만 갤러리에
들어간다. 결과물에 다음은 **없다.**

- 날짜 라벨(`Canvas/Button-Date-Select`, 예: `May 20 (Wed)`)
- 캔버스 좌상단의 잘린 모서리(컷) 장식
- `Canvas-Menu`(토핑 추가 / 캔버스 편집)

**UT에서 상당수 참가자가 날짜 라벨과 꺾인 프레임까지 그대로 저장된다고
인지했다.** 화면과 결과물 사이의 간극을 메우려고 저장 직전 미리보기를 넣는다.

**조사 결과가 화면 하나를 만든 사례다.** 기능정의서 v7이 같은 근거를 옮겨 적었다
([[mvp-scope-limits]]). **"인스타 스토리 바이럴용"**은 저장 이미지의 용도를
원본이 직접 밝힌 첫 문장이다 — 저장이 보관이 아니라 **바깥으로 퍼뜨리기 위한
것**이라는 뜻이다([[parfait]]).

UT 대상이 누구였는지는 이 문서에도 없다([[open-questions]]).

## 형태 결정 — 근거가 줄마다 붙었다

| 항목 | 결정 | 근거 |
|---|---|---|
| 노출 형태 | **풀스크린 페이지** | 파르페 안에 바텀시트 사용처가 0곳 → 새 패턴은 이질감 |
| 배경 | **White `#FAFAFA`** | A안 BK 딤·B안 Dot Grid 미채택. 결과물 색감을 가장 중립적으로 보여줌 |
| 액션 | **갤러리 저장 단일 CTA** | 인스타 공유 등 **외부 공유 기능이 아직 없음** |
| 저장 후 | **`C-001` 복귀 + Success 토스트** | 기존 확정 카피 재사용 |

**네 결정 모두 근거 열이 채워졌다.** "외부 공유 기능이 아직 없음"은 범위 밖으로 민
것을 **"아직"**이라는 낱말로 적었다 — 영구 제외가 아니라 미룬 것으로 읽힌다
([[mvp-scope-limits]]).

### 카피 (확정)

| 위치 | 문구 |
|---|---|
| 타이틀바 | `이미지 미리보기` |
| 헤드라인 | `May 20 (Wed) 의 캔버스를 갤러리에 저장할까요?` — 1줄 고정, `(Wed)`는 gray-300 |
| 서브 1 | `이 이미지 그대로 갤러리에 저장돼요` |
| 서브 2 | `파르페는 인스타그램 스토리 규격에 최적화되어 있어요` |
| CTA | `갤러리에 저장` |

**미리보기 이미지 = `Canvas-Area` 9:16 그대로이되 완전한 직사각형**이다. 컷
모서리·날짜 라벨·`Canvas-Menu`가 빠진다. 디자인 시스템을 따라 **radius 0**이다.

## 상태·예외

| 상황 | 동작 |
|---|---|
| 저장 성공 | `C-001` 복귀 + 토스트 `N월 N일의 캔버스가 갤러리에 저장돈어요`(원문 그대로) |
| 저장 실패(권한 거부·용량 부족 포함) | 토스트 `갤러리 저장에 실패했어요. 나중에 다시 시도해 주세요.` — **페이지 유지 여부 미결** |
| X 버튼 | 저장 없이 `C-001` 복귀 |
| Empty 캔버스 | 진입 불가 — 저장 아이콘 자체가 없다 |

**성공 토스트에 오타가 있다** — `저장돈어요`. 같은 날 편집된
[[src-common-서비스-공통-규칙-2026-09-20]]과 [[src-기능정의서-v7]]은
`저장됐어요`다. 원본을 고치지 않고 그대로 옮긴다([[toast]]).

**페이지 유지 여부가 "미결(5절)"이라 적혔는데 5절에 없다.** §5는 `v0.1` 대비
변경표이고 §6 미결 표는 세 줄이 전부 종결이며 넷째 줄이 빈 칸이다 —
**미결이라 적어 놓고 그 미결을 둘 자리가 비었다**([[open-questions]]).

## `v0.1`에서 무엇이 바뀌었나

원본 §5가 문서 정정 내역으로 남겼다.

| 항목 | `v0.1` | `v0.2` |
|---|---|---|
| 채택안 | A 딤 포커스 / B 페이퍼 / C 인포 중 선택 대기 | **셋 다 미채택, 통합 신안** |
| 배경 | A BK 딤 / B Dot Grid / C White | **White** |
| 프리뷰 크기 | 240×427(A·B) / 200×356(C) | **198×352** |
| CTA | `Button-Large` 335×48 풀폭 | `Button-Medium` 145×48 중앙 |
| 규격 표기 | `May 20 (Wed) · 1080 × 1920 px` | **수치 미표기** → "인스타그램 스토리 규격에 최적화" 문장 |
| 헤드라인 | 서술형("…저장돼요") | **질문형**("…저장할까요?") + 서술형 서브 |
| 화면 ID | 미결(`C-002`? `C-107`?) | `C-001-Save-Preview` |
| 제외 요소 안내 카피 | C안 "날짜 라벨과 잘린 모서리는 포함되지 않아요" | **미채택** — 프리뷰 이미지 자체로 인지시킨다 |

**`v0.1` 초안 날짜가 2026-09-01이다.** 시안 3안을 비교하던 단계였다.

**화면 ID 후보에 `C-002`가 있었다.** v2에서 정의되지 않은 채 v3가 없앤 편집 허브의
번호다([[screen-id-scheme]]). 재사용되지 않고 접미사 ID로 갔다.

**제외 요소를 글로 알리는 안을 버렸다.** UT가 드러낸 오해를 카피가 아니라 이미지로
푼다는 결정이다.
