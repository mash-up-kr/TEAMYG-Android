# 회의록 2026-10-20 전체회의

## 요약

2026년 10월 20일(화) 22:30 Discord 전체회의다. 10/15 UX_1 배포와 10/19 딥링크·영상
저장 배포 결과를 공유하고, 10/25 텍스트 업로드와 함께 낼 업무를 논의하며 **후속
작업 우선순위 8건**을 매겼다. 인스타그램 홍보 릴스 두 편의 캡션이 원본에 실렸다.

## 결정 사항

### 배포 결과

| 배포 | 내용 | 결과 |
|---|---|---|
| 10/15 | UX_1 (토핑 추가/편집 플로우 + `G-001` Empty Case) | Android·iOS·Spring 완료 |
| 10/19 | **초대 문구 딥링크** | Android·iOS 완료 |
| 10/19 | **갤러리 캔버스 영상 저장** | Android·iOS 완료 |

### 텍스트 업로드와 함께 낼 것

- 진척: Android 기능 구현 약 95%, iOS 클라 구현 완료·서버 연동 대기, Spring은
  "클라에서 지정한 필드 전달".
- **저장 버튼 UX를 바꿀지 → "우선 유저가 좀 더 모인 후에"**.

### 후속 우선순위

원본 순서 그대로다.

1. **푸시알림 인앱 제어**
2. **강제 업데이트**
3. **사진 촬영 시 줌인/줌아웃**
4. **공지사항 추가**
5. `C-001` Empty state 더미 배경
6. 홈 화면 위젯 (iOS)
7. 리뷰 유도 — "iOS 정책 검토 필요"
8. **누끼 외 특정 모양으로 사진 잘라주는 기능 (인스타그램 스토리처럼)**

### 홍보 릴스

- 두 편 모두 쓴다(밤티 릴스 / 감성 릴스). 홍보 기간 3일.
- 앱링크로 이동할 때 잠깐 뜨는 화면에 디자인을 추가한다(`DSN-A`).

## 범위·정책에 미친 영향

- **갤러리에서 캔버스를 영상으로 저장할 수 있게 됐다.** v7의 저장은 이미지
  한 장(`C-001-Save-Preview`)뿐이었다([[canvas]]). 영상 저장의 정의 문서는 이
  위키에 없다.
- **초대가 딥링크를 얻었다.** v7의 초대는 `S-101`에서 코드를 복사하는 것이었다
  ([[group]]). 이 딥링크가 이후 초대코드 시스템 공유 모달
  ([[src-회의록-2026-11-10-회의]])로 이어진다.
- **[[src-회의록-2026-10-06-회의]]의 우선순위가 바뀌었다.** 갤러리 시간 범위는
  이미 배포됐고, Empty 더미 배경과 위젯은 9·10위에서 5·6위로 올라왔으나 그 위에
  새 넷(인앱 알림 제어·강제 업데이트·줌·공지사항)이 끼었다.
- **사용자 문제를 팀이 어떻게 보는지가 홍보 문구에 적혔다.** 밤티 릴스 캡션은
  **"같이 놀아놓고 스토리는 왜 각자 꾸미는 거임? … 한 캔버스에 같이 꾸미고 한 번에
  올리면 되잖아 … 그거 그대로 스토리에 올려버려"**다. 감성 릴스는 **"친구들과 함께
  쌓은 오늘의 추억, 사진 한 장에"**다. 대상은 **함께 시간을 보낸 친구 무리**, 불편은
  **같은 추억을 각자 따로 스토리에 올리는 것**, 산출물의 행선지는 **인스타그램
  스토리**로 그려진다([[parfait]]). 조사 결과가 아니라 마케팅 문구다.
- **인스타그램 스토리가 행선지로 명시되면서 "외부 공유 없음"과 긴장이 생긴다.**
  [[mvp-scope-limits]]는 v7 근거로 "외부 공유 기능 미존재"를 적었다. 이 회의의
  8위(스토리식 모양 자르기)와 캡션, 그리고
  [[src-회의록-2026-11-03-회의]]의 인스타 스토리 바로공유가 그 결정을 되돌린다.
- 저장 버튼 UX 변경은 **사용자 규모를 기다리는 보류**다 — 근거가 사용자 수다.
