# Figma 주석 — 그룹 목록 (G-001)

## 요약

Figma `[디자인] 파르페 v0.1`의 `ㄴ 그룹 목록 (G-001)` 페이지 스냅숏이다.
2026-11-13 수집. 카드 5장이 전부 `DSN-B`, 07-20~07-22다. 이 페이지의 상세 정책은
따로 분리된 문서들이 맡고([[src-G-001-무한파르페-정책-v0.4]],
[[src-G-001-Empty-동작-명세-v0.3]]), 여기 남은 주석은 넷뿐이다.

## 화면 ID — v7과 비교

| 구분 | ID |
|---|---|
| 양쪽에 있다 | `G-001`, `G-001-Empty`, `G-001-Error`, `G-002` |
| v7에만 있다 | 없음 |
| 프레임에만 있다 | `G-001-1`, `G-001-2`, `G-001-4`, `G-001-5` |

- `G-001-1`~`5`는 v7이 "예시, 별도 페이지 아님"이라 적은 것인데 **`G-001-3`
  프레임이 없다.** 번호가 비는 이유는 없다.
- `G-002`(그룹 진입) 프레임(`1675:11158`)이 있다. v7이 복원하며 "그룹 목록 페이지
  내 프레임 존재"라 적은 것과 맞는다.
- `G-001-Empty` 프레임이 셋, `G-001-Error`가 넷이다. v7은 Error를 "4종"이라 적었다.
- 레이어에 `Template01`~`06`과 **`Template-Text-01`·`02`**, `Template-Error`가 있다.
  **텍스트 템플릿 둘은 빈 토핑 템플릿 6종 밖의 것이다.** 무엇인지 주석이 없다.

## 정책 문서에 없는 동작 주석

- **Error Case에서는 그룹 추가하기 버튼을 노출하지 않는다.**
- 스크롤 시 **안내 텍스트와 파르페 템플릿이 함께 내려간다**(고정되지 않는다).
- Empty 쪽 "애니메이션 재생", "화면 탭으로 인한 종료" — `G-001-Empty` 애니메이션
  동작이다. 세부는 [[src-G-001-Empty-동작-명세-v0.3]]에 있다.
