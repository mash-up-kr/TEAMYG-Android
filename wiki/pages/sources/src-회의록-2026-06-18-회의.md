# 6/18 전체회의 — v4 확인, 무한 파르페 정책 확정, 와이어프레임 최종 리뷰

## 요약

2026-06-18 21:00 Discord 전체회의. [[src-기능정의서-v4]] 확인, 무한 파르페 정책
검토(13개 항목 결정표), 와이어프레임 최종 리뷰, 개발 타임라인이 안건이다. 목적
달성란은 "무한 파르페 정책 최종 결정 ✅", "와이어프레임 확정 ✅"이고 개발 일정만
미확정이다.

검토 대상인 무한 파르페 정책 문서는 [[src-G-001-무한파르페-정책설계]](06-13)와
같은 계열로 읽힌다 — 항목 번호(정책 3·4·5·7·8.1·9.2·9.3)가 이 회의에 그대로
인용된다.

## 결정 사항

### 기능정의서 v4

- 명칭 수정([[src-회의록-2026-06-11-회의]]의 용어 표) 공유, 이견 없음 ✅
- **"탈퇴한 그룹 접근 방지 관련 G002 삭제"** ✅

### 와이어프레임 최종 리뷰

- 그룹 닉네임 기본값으로 **계정 닉네임 자동 입력**
- 그룹 참여 완료 후 **`G-001`로 이동**
- 지우개·테두리 최소·최대 크기는 추후 결정
- **`C-001` 진입 플로우 수정** — 플러스 버튼 → 카메라(`C-101`) / 갤러리(`C-102`)
  선택 먼저. 권한이 없으면 프리뷰 대신 권한 요청 UI와 **설정으로 이동** 버튼.
  제한된 사진 접근 상태면 권한을 다시 고르도록 설정으로 보낸다
- `S-001` 로그인 방식은 **카카오·애플 아이콘**으로만 표시
- **그룹 내 닉네임 중복 허용**

## 범위·정책에 미친 영향

- **정렬 기준에 확정 문장이 생겼다.** 06-13 정책 문서에는 투표 결과만 있었는데
  이 회의 결정표가 "활동순"을 결정으로 적었다([[group]], [[infinite-parfait]]).
- **그룹명 잘림을 px 기준으로 바꾼 것이 이 회의다.** 06-13 문서의 "6자 / 앞 5자 +
  …"를 07-22 간격 정책서가 80px로 바꾼 것으로 이 위키는 기록해 왔는데, 방향은
  이미 06-18에 정해졌다([[infinite-parfait]]).
- **캐싱 안 함도 이날 정해졌다.** 이 위키는 정책설계 `v0.2`에서 이 항목이
  취소선으로 지워지고 `v0.3`에서 "종결"됐다고 적어 왔다
  ([[src-G-001-무한파르페-정책설계-v0.3]]). 결정은 그보다 앞선다.
- **`A-003` 제거와 `G-001` Empty Case**가 [[src-기능정의서-v5]]에서 `A-003`이
  약관 동의로 바뀌고 그룹 참여/생성 선택 화면이 사라진 이유다. 위키는 이것을
  "참조가 남은 채 정의가 바뀐 것"으로 추적해 왔는데 의도는 이 회의에 있었다.
- **`G-002` 삭제가 v4 확인 자리에서 결정됐다.** 이 위키는 v4·v5의 `G-002` 행을
  "캡처 공백"으로, 삭제를 [[src-기능정의서-v6]]의 일로 적어 왔다
  ([[screen-id-scheme]]). 삭제 사유는 "탈퇴한 그룹 접근 방지"로만 적혀 있어,
  권한 검증을 없앤 것인지 다른 곳으로 옮긴 것인지는 여전히 읽히지 않는다.
- **`C-101`/`C-102` 선택 분기와 권한 UI**가 [[topping-placement-pipeline]]의
  진입부를 정했다.
- **그룹 내 닉네임 중복 허용과 계정 닉네임 기본 입력**이 여기서 나왔다. 기능정의서는
  [[src-기능정의서-v7]]에서야 중복 허용을 적었다([[account]]).
