# 캔버스

## 정의

그룹 하나의 하루에 대응하는 공유 편집 영역이다. 배경 한 장과 그 위에 놓인 객체
여러 개로 이뤄진다. 객체는 구성원이 올린 누끼 사진이다.

캔버스는 사람이 만들지 않는다. **매일 00:00에 그룹별로 빈 캔버스가 자동 생성된다**
(`SY-003`). 기본 비율은 16:9다. 그룹에 들어가면(`G-002`) 그날의 캔버스가 곧바로
열린다(`C-001`).

## 일일 주기

하루가 캔버스의 수명이다. 00:00 KST에 두 가지가 같이 일어난다.

1. **마감**(`SY-001`) — 그날 캔버스를 닫고 완성된 그림을 이미지로 추출한다.
   추출한 이미지는 그룹에 보존하고, 사용자 갤러리 저장은 선택이다.
2. **생성**(`SY-003`) — 다음 날치 빈 캔버스를 그룹별로 만든다. 생성이 실패하면
   재시도하고, 첫 진입자가 빈 상태를 트리거하면 fallback으로 생성한다.

갤러리 저장 버튼은 **마감된 캔버스에만 보인다**(`SY-002`). 시간대는 서버 기준
KST로 고정한다.

마감된 캔버스는 지나간 날짜로 다시 열어볼 수 있다(`C-201`). 객체를 탭하면 올린
사람의 닉네임이 뜬다(`C-202`) — 오늘 캔버스와 과거 캔버스 모두에서 동작하고,
탈퇴한 사용자는 '알 수 없음'으로 표기한다.

## 편집 권한과 동기화

그룹 구성원이면 누구나 자유롭게 편집한다. 편집 결과는 실시간으로 다른 구성원
화면에 반영된다. 배치 확정(`C-106`)과 배경 변경 확정(`C-305`)이 그룹원에게
브로드캐스트되는 지점이다.

동시 편집이 충돌하면 **last-write-wins**를 적용한다. 동기화가 실패하면 마지막
캐시를 보여주고 Pull-to-refresh를 제공한다.

사진을 올린 뒤 위치를 고치는 것은 **자기 사진에만** 허용된다(`C-108`).

## 배경

배경은 세 방법 중 하나로 바꾼다(`C-301`) — 촬영(`C-302`), 갤러리(`C-303`),
단색(`C-304`). 앞의 두 방법은 [[cutout-placement-pipeline]]의 누끼 단계로
들어간다. 바꾼 배경은 확정 시 저장되고 브로드캐스트된다(`C-305`).

캔버스 위에 올라가는 사진의 투입 경로는 [[cutout-placement-pipeline]]에 있다.
캔버스를 소유하는 단위는 [[group]]이다. 화면 ID 표기 규칙은
[[screen-id-scheme]]을 따른다.

## 미결

- 실시간 반영을 WebSocket으로 할지 폴링으로 할지 정해지지 않았다.
- 과거 캔버스 조회 가능 기간(예: 30일)이 정해지지 않았다.
- 마감 시점에 작업 중인 객체를 어떻게 처리할지 정해지지 않았다.
- `C-304`(배경 색 설정)와 `SY-002`(마감 갤러리 저장)는 소스의 세부 열이 비어 있다.
