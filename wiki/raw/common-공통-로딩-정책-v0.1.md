# 1. 로딩 애니메이션

## 에셋

- 원문에 **로티 파일 링크**("바로가기 →" 하이퍼링크)가 걸려 있다. 링크 대상 URL은 스크린샷에 노출되지 않아 수집되지 않았다.
- 파일 2종을 **각각 전달**한다.
  - `Lottie_Loading_Light.lottie`
  - `Lottie_Loading_Dark.lottie`
- 재생 방식: **loop 재생**.

## 규격

| 항목 | 값 |
| --- | --- |
| 크기 | 44x44 |
| 프레임레이트 | 60fps |
| 길이 | 2초 (120프레임) |

## 사용처

| 파일 | 사용처 |
| --- | --- |
| 라이트 | **공통 로딩** (Black-75 딤처리) |
| 다크 | **그룹 목록 pull to refresh** (G-001-Error 참고) |

## 배치

- **중앙 정렬**.

# 원문에 명시되지 않은 사항

- **크기 44x44의 단위**가 기재되지 않았다(dp·pt·px 중 무엇인지 원문에 없음).
- **"라이트 / 다크"의 의미**가 정의되지 않았다. 원문은 두 파일을 앱 테마가 아니라 **사용처**로 갈라 놓았다 — 라이트는 공통 로딩, 다크는 그룹 목록 pull to refresh다. 따라서 이 이름이 ⓐ 에셋 자체의 명암을 가리키는 것인지 ⓑ 앱의 라이트·다크 테마 대응인지 원문만으로는 확정되지 않는다. ⓑ라면 "공통 로딩"과 "pull to refresh"라는 사용처 구분과 서로 어긋난다.
- **Black-75 딤처리의 적용 범위**가 기재되지 않았다(화면 전체인지 특정 영역인지, 딤 위에서 화면 조작이 가능한지).
- **`G-001-Error`** 를 참고 문서로 지목하나 해당 문서는 수집되지 않았다.
- **로딩 노출·해제 조건**(최소 노출 시간, 타임아웃, 실패 전환)이 없다. 이 문서는 애니메이션 에셋 규격만 다룬다.
