#### 본문 `2025:14569`

```text
1. 캘린더 열기·닫기 동작
 
1.1 열기
- 날짜 프레임 우측 캘린더 아이콘 버튼 탭 → 캘린더 오픈
- 오픈 시 배경에 딤드(반투명 오버레이) 노출
- 오픈 시 표시되는 연/월은 항상 고정 규칙 : 현재 보고 있는 캔버스 날짜가 속한 연월을 노출한다
  예외 없음. 직전에 캘린더 안에서 다른 연/월을 탐색해봤어도 무관하게, 캘린더를 열 때마다 이 규칙이 매번 적용된다 (4.3 참고)
 
1.2 닫기 (트리거 2종 — 동일 동작)
- 캘린더 아이콘 버튼 재탭(토글) → 캘린더 닫힘
- 딤드 처리된 영역 탭 → 캘린더 닫힘
- 두 트리거 모두 동일하게 "그냥 닫힘" — 일자 미선택 상태로 닫히면 화면(캔버스)은 이동하지 않음
 
1.3 연/월만 바꾸고 일자를 선택하지 않은 채 닫는 경우
- 연/월 드롭다운으로 이동만 해둔 상태(예 2026년 5월 → 2027년 3월 그리드까지 넘겨봄)에서 일자를 탭하지 않고 4.2의 트리거로 닫으면
  캔버스는 이동하지 않는다 (원래 보고 있던 날짜 그대로 유지)
  캘린더 내부에서 바꿔둔 연/월 탐색 상태는 항상 폐기(discard)된다. 세션 내 유지 없음
  다음에 캘린더를 다시 열면 1.1대로 무조건 "현재 보고 있는 캔버스 날짜"가 속한 연월부터 시작한다
  (예 2027년 3월까지 넘겨봤어도 저장되지 않고, 캔버스가 여전히 May 2026을 보고 있었다면 다시 열었을 때 May 2026 그리드로 노출)
 
 
2. 연·월 선택 동작 (하위 리스트)
 
2.1 진입
- 상단 "May" / "2026" 각각 탭하면 해당 리스트(월 리스트 / 연도 리스트) 노출
- 월 리스트, 연도 리스트는 동시에 함께 열리지 않음. 한쪽을 열면 다른 한쪽(또는 날짜 그리드)은 닫힘
 
2.2 항목 선택 — 확인 버튼 없이 즉시 반영
- 리스트에서 항목(월 또는 연도) 탭 → 별도의 확인·이동하기 버튼 없이, 탭한 즉시 그 값으로 날짜 그리드가 갱신되고 날짜 그리드 화면으로 자동 복귀
- 이 시점에는 캔버스 이동이 발생하지 않음. 그리드 재렌더링만 일어남 (Today/Selected/Disabled/Chip-Indicator는 새 연/월 기준으로 재계산)
 
즉, 연/월 각각의 선택은 독립적으로 즉시 적용되며, 두 값을 다 맞춘 뒤 별도로 "확인"할 필요가 없다
최종적으로 일자를 탭해야 캔버스 이동이 발생
 
2.3 리스트가 열린 상태에서 닫기
- 월 리스트 또는 연도 리스트가 열린 상태에서 딤드 영역을 탭하면 → 리스트만 닫히고 날짜 그리드로 복귀. 캘린더 자체는 오픈 상태 유지
- 캘린더를 완전히 닫으려면 : 리스트를 먼저 닫아 날짜 그리드로 돌아온 뒤, 딤드를 한 번 더 탭하거나 캘린더 아이콘을 재탭
 
2.4 연도 리스트 — 노출 범위 및 Disabled 규칙
- 하한 : 배포연도(2026) 미만은 노출하지 않음. 업로드 자체가 불가능했던 기간이므로 리스트에 아예 표시 안 함
- 상한 : 오늘 기준 현재연도를 초과하는 미래 연도는 노출하지 않음. 날짜 선택의 기획 의도가 "과거에 뭘 올렸는지 보기"이므로, 아직 오지 않은 연도(전부 빈 캔버스)는 노출 자체가 불필요
- 노출 범위 : [배포연도, 현재연도] 구간만 리스트에 표시 (예 오늘이 2026년이면 2026 단 1개 항목만 노출)
- Disabled 처리 : 노출 범위 안에 있는 연도라도, 해당 연도 전체에 업로드된 토핑이 0개면 항목은 노출하되 Disabled(탭 불가, 선택 불가능)
- 정렬 : 오름차순 (과거 → 현재)
 
2.5 월 리스트 — 노출 범위 및 Disabled 규칙
월 리스트는 현재 헤더에 선택되어 있는 연도 기준으로 범위가 달라진다
- 하한 : 선택된 연도가 배포연도(2026)인 경우 → 배포월(9월) 미만 노출 안 함. 배포연도보다 큰 연도인 경우 → 1월부터 노출
- 상한 : 선택된 연도가 현재연도인 경우 → 현재월 초과 노출 안 함. 현재연도보다 과거 연도인 경우 → 12월까지 노출
- Disabled 처리 : 노출 범위 안에 있는 월이라도, 해당 월 전체에 업로드된 토핑이 0개면 항목은 노출하되 Disabled
- 정렬 : 오름차순 (1월 → 12월, 범위 내에서)
 
2.6 리스트 내부 스크롤 발생 기준
- 항목 1 ~ 5개 : 풀 노출. 항목이 추가될 때마다 리스트 컨테이너 높이가 아래로 그만큼 늘어남 (내부 스크롤 없음)
- 항목 6개 이상 : 리스트 컨테이너 높이 max-height 220px 고정 + 내부 스크롤 발생
- max-height 산식 : 항목(연도/월) 버튼 높이 44px × 5행 = 220px
- 현재(2026-07 시점) 실사용 노출 개수 : 연도 리스트 = 2026 1개, 월 리스트 = 9월 1개 → 둘 다 220px 미만이라 스크롤 미발생
 
3. 일자 선택(이동) 동작
- Button-Date(Disabled 제외) 탭 → 즉시 해당 날짜의 캔버스로 이동하며, 동시에 캘린더(드롭다운 포함) 자동 닫힘
- 연/월을 이동시켜 놓은 상태에서 일자를 탭한 경우 : 그 탭한 연/월의 날짜가 그대로 반영되어 이동
  (4.3의 "폐기"는 일자 미선택 시에만 적용되며, 일자를 탭하면 그 순간의 연/월+일이 확정값이 된다)
- Disabled 날짜는 탭 자체가 불가(터치 영역 무반응)
```
