# 무한 파르페 정책 설계서 v0.3 (G-001)

> 그룹 목록 메인 화면. 그룹이 늘수록 파르페 템플릿이 아래로 무한히 길어지고,
> 각 그룹의 최신 대표 토핑이 **지그재그 패턴(행당 1개, 좌/우 번갈아)**으로 크림 위에 쌓인다.

## 5. 갱신(새로고침) 정책

- Pull-to-Refresh로 전체 목록 다시 조회
- 새로고침 시 기존 리스트를 전체 교체하며 스크롤 위치는 최상단으로 초기화
- 화면 재진입 시 최신 활동 시간 반영을 위해 **자동 재조회 진행 (확정)**

### 5.1 그룹 나가기 정책

- 그룹 나가기 → 해당 토핑이 목록에서 빠짐.
- **빈자리 없음**: 나간 토핑 위치 뒤의 토핑들이 정렬 순서 그대로 한 칸씩 위로 당겨짐.
- **지그재그 재배정**: side는 `index % 2`라, 한 칸 당겨지면 당겨진 지점 이후 모든 토핑의 좌/우(및 타입·회전)가 바뀜 → 버그 아니라 정상 동작.
    - 변형 번호(1/2/3)도 **함께 랜덤 재부여된다** ✅ (그룹 ID 고정 시드 아님 — 8.2 참고). 구 "변형 시드는 그룹 ID 고정이라 유지" 서술 **폐기**.
- 크림은 그만큼 수축, 접시가 위로 올라옴.
- 반영 시점: 저장·화면 재진입 시 (실시간 아님 — 기존 동기화 정책)

## 8. 그리드 배치 정책

### 8.1 배치 패턴

- 리스트는 지그재그(행당 1개, 좌/우 번갈아) 패턴으로 반복 배치
- 위에서 아래로 좌 → 우 → 좌 → 우 무한 반복
- 첫 번째 토핑(index 0)은 **Left 고정**으로 시작

```
[ Left ]
         [ Right ]
[ Left ]
         [ Right ]
[ Left ]
...
```

**저개수 특수 배치**

- **N = 0** → 토핑 없음. 크림 기본(3개) + 접시. 안내는 온보딩 툴팁(G-001-Empty)이 담당
- **N = 1 / 2 / 3** → 스크롤 발생하지 않음. 여백 고려하여 N ≥ 4 배치 대비 각 토핑 y를 **+12 내림(아래로)**. x는 동일. 파르페 세로 성장 없음.
- **N = 4 이상** → 스크롤 발생. 기준 y 그대로 적용(+12 없음). 크림 추가(세로 성장) 시작 — 토핑 1개 늘 때마다 크림 1개씩 증가.

### 8.2 인덱스 기반 규칙

아이템 순서를 0부터 셀 때, 2개 단위 반복 (좌/우 번갈아)

| 그룹 내 위치 (index % 2) | side |
| --- | --- |
| 0 | Left |
| 1 | Right |

**좌표 및 세로 갭**

- **기준 x (고정)**: 전체 템플릿(가로 **324.3**) 기준 — Left = 좌측 인셋 **4** (x=4) / Right = 우측 인셋 **4** (x=160.3)
    - 좌표 컨테이너는 **크림이 아니라 파르페 템플릿 전체**(체리~접시 포함 고정 이미지 영역). 화면 기준 아님
    - Left↔Right 가로 관계는 **3.7 (겹침)** — 템플릿 폭에서 자동 결정되는 **파생값**, 직접 지정하지 않음
    - 토핑·칩이 크림 폭을 넘는 것은 **정상 동작**. 경계는 크림이 아니라 템플릿
- **첫 토핑(Left, index 0) y = 268** — N ≥ 4 (스크롤 발생) 기준. N = 1 / 2 / 3은 스크롤이 없어 **+12 내린 280**.
- **같은 side 세로 갭 = -12**
    - Left 열: y = **268, 416, 564, …** (+148)
    - Right 열: y = **354, 502, 650, …** (+148)
- **Right 토핑은 인접한 두 Left 토핑 사이 높이**에 배치 (실측 기준 **Left y + 86**)
- 변형 번호(1/2/3)는 세로 갭에 영향 없음 — 같은 side면 -12 동일
- 상세 수치·산식은 `raw/G-001-무한파르페-간격-정책-v0_2.md` 참고

**템플릿 고정 갭**

| 구간 | 갭 |
| --- | --- |
| 체리 ↔ 첫 토핑 | -65 |
| 마지막 토핑 ↔ 접시 | -48 |
| 접시 하단 갭 | 최소 16 (스크롤 발생 시에만 적용 — 토핑 3개까지는 스크롤 없어 해당 없음) |

**토핑 규격 · 타입별 변형**

토핑 = **Img + Grouptag-Chip**, 6타입 (`Left-1/2/3`, `Right-1/2/3`)

- 토핑 프레임: **160×160** / Img: **96×96**
- **오버플로우 없음**: 96 Img는 160 프레임을 회전·이동(풀블리드 포함)해도 절대 벗어나지 않음 → 구 clip OFF / 삐짐 노출 정책 **삭제**
- Chip: 회전 없음. Timestamp 텍스트 컬러 = `프로필 이미지 및 토스트 닉네임 텍스트 컬러 규칙` 준수 (랜덤 X)
- Z: **Img > Grouptag-Chip** (항상)
- Left 토핑은 `Left-1~3`, Right 토핑은 `Right-1~3` 중 하나의 타입을 **랜덤 부여**받음 ✅ 확정
    - 그룹 토핑은 활동 최신순 정렬이므로, 새로고침 시 정렬에 변동이 있으면 타입이 바뀜
    - 예: 어떤 그룹이 3번째 활동 → Left-3 적용 → 새로고침으로 5번째로 순서 변동 → Left-1/2/3 중 하나로 변경
    - **재추첨 시점 = 목록 조회 응답 1회.** 리렌더·셀 재사용 시 재추첨 금지 (회전각 튐 방지) — 상세는 `raw/G-001-토핑-정책-v0_2.md` 4.2

### 9.3 라벨

**그룹 이름 처리**

칩(라벨 pill)은 한 줄 고정, 토핑 우측 하단 배치.

- 그룹명 **80px 초과 시 초과분부터 `…` 처리** (픽셀 기준)
    - ❌ 구 "최대 노출 6자 / 7자 이상 → 앞 5자 + `…`" 문자수 기준 규칙 폐기
- 시간 텍스트(`N분 전`)는 항상 전체 노출, 줄이지 않음
- 칩 폭은 토핑 폭에 종속시키지 않고 내용 기준으로 늘어남
- Timestamp 텍스트 컬러 = `프로필 이미지 및 토스트 닉네임 텍스트 컬러 규칙` 준수 (랜덤 X)

**상대 시간 표기 기준**

대표 토핑의 마지막 활동 시각 기준.

| 경과 시간 | 표기 |
| --- | --- |
| 60초 미만 | 방금 전 |
| 1분 ~ 59분 | N분 전 |
| 1시간 ~ 23시간 | N시간 전 |
| 1일 ~ 6일 | N일 전 |
| 7일 이상 | 오래 전 |

**NEW 기준**

- 그룹을 무조건 선택해야 읽은 것으로 판단 (C-001 진입 필요)
- 그룹이 스크린에 노출되는 것만으로는 NEW 표시가 사라지지 않음

### 9.4 크림

**가로폭 ✅ 확정 — 고정 이미지 + 중앙 정렬**

- 크림은 **고정 이미지 에셋**으로 처리한다. 비율 고정.
- **화면 폭에 비례해 늘어나지 않는다.** 넓은 기기를 써도 크림 가로 너비는 동일하며, 좌우 여백만 늘어난다.
- 정렬: **중앙 정렬**
- ❌ 폐기: 1안(크림 가로폭 = 그리드 전체 크기와 동일 / 화면 폭 추종)

> ✅ 파생 이슈 해소 — 토핑 x는 **전체 템플릿(324.3) 기준 좌/우 인셋 4**로 확정(8.2절). 좌표 컨테이너는 크림이 아니라 템플릿 전체이므로, 토핑·칩이 크림 폭을 벗어나는 것은 **정상 동작**이며 템플릿 밖으로는 나가지 않는다(테스트 확인).

**개수**

| 토핑 수 | 크림 수 |
| --- | --- |
| 0 ~ 3개 | 3개 (기본) |
| 4개 | 4개 |
| 5개 | 5개 |
| N (N ≥ 4) | N |

- 즉, 4개부터 토핑 1개 추가 시 크림 1칸 추가.
