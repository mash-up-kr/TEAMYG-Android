- **v6 대비 주요 변경**:
  - 화면 17건 신규 추가(푸시 `P-*` 3건·튜토리얼 `Tutorial-*` 5건 포함), `C-301`(캔버스 편집 모드 진입) 삭제, `G-002`(그룹 진입) 복원
  - 컬럼 2종 신설 — `릴리즈`(해당 화면이 반영된 배포 버전), `v7 상태`(신규/변경/유지/복원)
  - `기타` 컬럼에 개별 정책 문서(C-001 캔버스 정책 v0.3, 저장 미리보기 정책 v0.2 등)의 본문이 직접 전재됨

> 협업 캔버스 앱의 화면 단위 기능정의 7차. 화면 ID 접두사: `A-`(Auth), `G-`(Group), `C-`(Canvas), `S-`(Sidebar), `SY-`(System), `P-`(Push), `Tutorial-`(온보딩 튜토리얼).
>
> ℹ️ **담당자·진행상황 컬럼 없음**: v6에서 raw 제외 대상이던 담당자(인물)·진행상황 컬럼이 v7 원본에는 아예 존재하지 않는다. 대신 `릴리즈`·`v7 상태` 컬럼이 그 자리를 대체한다.

> 🔒 **실명 마스킹됨**: public repo이므로 입력 예시에 쓰인 팀원 실명 2종을 더미 이름으로 치환했다. 통과 예시는 `홍 길동`(공백 1칸), 불통과 예시는 `홍  길동`(공백 2칸 연속)이다. 공백 개수 자체가 규칙 시연의 핵심이므로 마크다운 원문에는 연속 공백을 그대로 보존했으나, 렌더링 화면에서는 두 칸이 한 칸으로 합쳐져 보인다. 원본 대응은 git 추적 제외 위치 `wiki/personal-private/담당자-매핑.md` 참고. CLAUDE.md 공통규칙 6 참고.

> 📐 **표기 규칙**: 원본 CP949 판본은 UTF-8 판본에서 일부 기호가 치환된 상태다(`—`→`-`, `☰`→`≡`, `✓`→`√`, `⇄`→`↔`, `…`→`...`). 텍스트 내용은 동일하며 본 문서는 CP949 판본을 그대로 따른다.
>
> 원본 셀 중 160자를 넘는 `분기조건`·`시스템 동작`·`예외처리`·`기타` 값은 표 가독성을 위해 아래 [화면별 상세](#화면별-상세)로 옮기고, 표에는 링크만 남겼다. **내용은 한 글자도 생략하지 않았다.**

## v6 → v7 변경 요약

### 표 구조 변경

- **컬럼 신설 2종**: `릴리즈`(v1.0.0 5건 / v1.0.1 39건 / `배포 전` 1건 / 공백 9건), `v7 상태`(신규 9건 / 변경 24건 / 유지 13건 / 복원 1건 / 공백 7건).
- **컬럼 순서 변경**: v6은 `시스템 동작`·`기타`가 앞쪽에 있었으나, v7은 `진입 경로`·`다음 단계`·`분기조건` 뒤로 이동했다.
- **`기타` 컬럼의 성격 변화**: v6에서는 짧은 비고였으나, v7에서는 개별 정책 문서의 본문(캔버스 정책 v0.3, 저장 미리보기 정책 v0.2, 누끼·테두리 렌더링 정책, G-001 좌표·변형 상수 등)이 통째로 전재되어 있다.

### 화면 추가 (17건)

- **푸시 계열 신설 3건**: `P-01`(토핑 등록 알림, C-106 저장 시점 본인 제외 전체 발송·묶음/상한/쿨다운 없음), `P-02`(오전 리마인드 10:00 KST), `P-03`(저녁 리마인드 20:00 KST). 분류 `Push` 신설.
- **튜토리얼 계열 신설 5건**: `Tutorial-1`~`Tutorial-5`. 1~3은 캔버스 최초 진입 3단계 안내, 4는 토핑 업로드 안내(C-102 위), 5는 토핑 수정 안내(C-103 위).
- **상태 화면 독립 행 분리 6건**: `C-001-Loading`·`C-001-Error`·`G-001-Error`·`C-102-Empty`·`G-001-Empty`·`C-103-Error`. v6에서 예외처리 문구로만 존재하던 로딩·실패·빈 상태를 별도 행으로 승격했다.
- **신규 기능 화면 2건**: `C-001-Save-Preview`(캔버스 저장 미리보기 풀스크린), `A-006`(그룹 참여 중 닉네임 입력, 피그마 `A-004-naming`을 분리).
- **복원 1건**: `G-002`(그룹 진입). v5에 있었고 v6에서 삭제됐다가 v7에서 복원됐다. 이에 따라 A-004·A-005의 다음 단계가 `C-001` → `G-002`로, C-001의 진입 경로가 공백 → `G-002`로 되돌아갔다.

### 화면 삭제 (1건)

- **`C-301`(캔버스 편집 모드 진입) 삭제**: v6 페이지 비고의 "에딧 모드 삭제"가 v7에서 실제로 반영됐다. C-301이 담당하던 편집 모드 진입은 `C-304`(캔버스 수정)가 배경 탭·토핑 탭으로 흡수했고, 진입점은 C-001 Canvas-Menu 1뎁스의 "캔버스 편집 >"이다. 이에 따라 `C-302`·`C-303`·`C-305`의 진입 경로도 C-301 → C-304로 재배선됐다.

### 화면 ID 대소문자 표기 통일 (8건)

`C-101-confirm`→`C-101-Confirm`, `C-101-error`→`C-101-Error`, `C-102-confirm`→`C-102-Confirm`, `C-102-error`→`C-102-Error`, `C-103-loading`→`C-103-Loading`, `C-103-select`→`C-103-Select`, `SY-001-closed`→`SY-001-Closed`, `SY-001-new`→`SY-001-New`. 접미사 첫 글자를 대문자로 통일했다.

### 주요 정책 변경

- **C-001 캔버스 정책 v0.3**: 탭바 개념 삭제, 3탭 모드 스위칭(파르페 홈/쌓기/배경) 폐기. 구 v0.2 Background Blur(상시 Black-25·Uniform·Blur 4)를 폐기하고 **Dot Grid 배경**(간격 22px, 도트 2×2)으로 전면 교체. Canvas-Area 9:16 비율은 Canvas-Menu 44px를 제외하고 계산한다.
- **저장 아이콘 노출 조건 변경**: 구 정책 「저장 버튼은 마감 시에만 노출」을 폐기하고, **Empty 상태에서만 미노출·그 외에는 마감 여부와 무관하게 항상 노출**로 바꿨다(`SY-001-Closed`·`C-001` 양쪽에 기재).
- **저장 플로우에 미리보기 단계 추가**: UT에서 다수 참가자가 날짜 라벨과 꺾인 프레임까지 저장된다고 인지해 `C-001-Save-Preview`를 신설했다. 실제 저장 대상은 컷 모서리·날짜 라벨·Canvas-Menu가 제외된 완전한 직사각형 9:16이다.
- **C-201 캘린더 상세화**: 연/월 리스트 노출 범위(하한 배포연도 2026·배포월 9월, 상한 현재연월), 리스트 max-height 220px(44px × 5행), 연/월 탐색 상태 미선택 시 폐기 등이 확정됐다.
- **누끼 실패 분기 신설**: `C-103-Error`에서 플랫폼별 버튼 구성이 갈린다 — Android는 다시 시도·직접 편집, iOS는 편집 없이 사용·직접 편집.
- **C-103 성공 시 목적지 변경**: 자동 누끼 성공 시 v6은 C-104/C-105 병렬이었으나 v7은 **C-105(테두리) 직행**이고, 수동 편집을 선택해야 C-104로 간다.
- **폴링 추가**: C-001 실시간 동기화에 10초 주기 자동 갱신 병행이 명시됐다.
- **푸시 토큰 생명주기**: 탈퇴(S-003)·로그아웃(S-005) 시 푸시 토큰은 soft delete 대상이 아니라 **즉시 하드 삭제**한다.
- **S-103 그룹 나가기**: 마지막 1인이 나가면 그룹과 캔버스 전체를 삭제하고, 남은 그룹원이 있으면 내 토핑을 익명화 보존한다.
- **A-003 다음 단계 변경**: v6은 약관 동의 후 `G-001`이었고 v7도 `G-001`이나, A-004·A-005의 진입 경로가 `A-003` → `G-001`로 바뀌어 그룹 참여·생성이 **약관 동의 직후가 아니라 그룹 목록에서** 시작하는 흐름으로 정리됐다.

## 원본 공백 / 불일치

- **행 순서 불연속**: 원본 마지막 6행(`C-001-Loading`·`G-001-Error`·`A-006`·`C-001-Error`·`C-102-Empty`·`Tutorial-4`)은 ID 정렬 순서를 벗어나 표 끝에 덧붙어 있고 `릴리즈`·`v7 상태`가 모두 공백이다. 뒤늦게 추가된 행으로 보이나 원본 순서를 그대로 보존했다.
- **`Tutorial-2`·`Tutorial-3` 기능명 공백**: 두 행은 화면 ID·분류·진입 경로·다음 단계만 채워져 있고 기능명·시스템 동작·기타가 전부 비어 있다.
- **`Tutorial-5` 위치**: 원본 표에서 `Tutorial-4`보다 앞(48행)에 있고 `Tutorial-4`는 맨 끝(54행)에 있다.
- **`C-104` 릴리즈 `배포 전`**: 다른 행은 `v1.0.0`/`v1.0.1` 형식인데 이 행만 문자열 `배포 전`이다. 아울러 예외처리에 "v1.0.1 기준 확대·축소·이동이 동작하지 않는 결함"이 기재되어 설계와 구현이 어긋난 상태임을 원본이 스스로 밝히고 있다.
- **튜토리얼 존폐 미결**: `Tutorial-4`·`Tutorial-5` 모두 "다음 빌드에서 튜토리얼 삭제 후 누끼 플로우 재편 예정"이라 적혀 있으나, `Tutorial-1`~`3`의 존폐는 언급이 없다.
- **`C-001-Save-Preview` 실패 처리 미결**: 저장 실패 토스트 노출 후 "페이지 유지 여부는 미결"이라고 원본에 명시돼 있다.
- **`C-001-Empty` 카피 미확정**: 원본이 "첫번째 토핑을 올려"가 브랜드 동사 규칙(쌓다 확정, 올리다 금지)과 충돌한다며 "쌓아"로 변경을 권고하고 있으나, 확정 카피가 아니라 권고 상태로 남아 있다.
- **`P-01` 푸시 예외 프레임 미상**: "푸시알림 예외케이스 코드 E-04 / E-07 프레임이 캔버스 페이지에 존재 (상세 내용 확인 필요)"로 원본이 미확인임을 표기하고 있다.
- **화면 ID 대소문자 혼용 잔존**: 행의 화면 ID는 `C-101-Confirm`·`C-103-Loading`처럼 대문자로 통일됐으나, 다른 행의 `다음 단계`·`진입 경로` 셀에는 `C-101-confirm`·`C-101-error`·`C-103-loading`·`C-103-select` 같은 구 소문자 표기가 그대로 남아 있다.
- **`S-001` 구버전 컴포넌트 잔존**: "Profile-Card-수정 전 컴포넌트 존재(구버전 프로필 카드)"가 기재돼 있다.
- **`A-002-1/2/3` 표기**: 로그인 온보딩 가로 스크롤 그래픽 순서일 뿐 별도 페이지가 아니라고 A-002에 명시돼 있으나, `S-005` 로그아웃의 다음 단계는 `A-002`이고 시스템 동작 설명은 `A-002-1`로 적혀 있어 표기가 섞여 있다.
