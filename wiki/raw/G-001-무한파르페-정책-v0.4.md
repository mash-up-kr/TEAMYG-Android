### 1. 개요

> 그룹이 늘수록 파르페 템플릿이 아래로 무한히 길어지고, 각 그룹의 최신 대표 토핑이 **지그재그(행당 1개, 좌/우 번갈아)**로 크림 위에 쌓인다.

- 적용 플랫폼: Android, iOS

- 진입: A-001, S-001, P-02·P-03 푸시 / 다음: A-004, A-005, G-002, S-001, G-001-Error

### 2. 데이터 모델

| 필드 | 노출 |
| --- | --- |
| 그룹 ID | ❌ |
| 프리뷰 이미지 (대표 토핑) | ✅ 고정 사이즈 |
| 그룹 이름 | ✅ |
| 최근 활동 시각 | ✅ (상대시간) |

### 3. 조회 정책

- **1회 API 호출**로 전체 조회, 페이지네이션 없음

- 정렬: **최근 활동순.** 밀리초까지 동일하면 **그룹 생성일시 최신순**

- 그룹 목록은 캐싱하지 않음(재진입 시 자동 재조회), 프리뷰 이미지만 지연 로딩 + 캐싱

### 4. 상태별 동작

| 상태 | 화면 표현 |
| --- | --- |
| 초기 로딩 | 자체 로딩 그래픽 |

| 토핑 내 이미지 없음 (아직 아무도 안 쌓음) | 토핑 템플릿 그래픽 6종(Template01~06) 중 1종을 랜덤 최초 부여하고 고정. 새로고침·재접속·타 그룹 갱신에도 변경되지 않음 |

### 5. 갱신 정책

- Pull-to-Refresh: 전체 교체 + 스크롤 최상단. 로딩 `Lottie_Loading_Dark.lottie` (44×44 / 60fps / 2초 120프레임, loop, 중앙)

- 화면 재진입 시 자동 재조회

#### 5.1 그룹 나가기

- 해당 토핑 제거, 빈자리 없이 뒤 토핑이 정렬 순서 그대로 한 칸씩 당겨짐

- side는 `index % 2` 재계산 → 당겨진 지점 이후 좌/우·타입·회전이 바뀜 (정상 동작). 변형 번호도 함께 랜덤 재부여

- 크림 수축, 접시 상승. 반영 시점은 저장·화면 재진입 시

### 6. 배치 정책

#### 6.1 패턴

- 지그재그, 위→아래 좌→우 반복. index 0 = Left 고정

- `index % 2` → 0 Left / 1 Right

#### 6.2 저개수 특수 배치

| N | 정책서 v0.3 | 기능정의서 v7 |
| --- | --- | --- |
| 0 | 토핑 없음. 크림 **기본 3개**  • 접시 | 토핑 없음(크림 **최소**  • 접시) — 클라이언트 확인 필요 |
| 1 / 2 | 스크롤 없음, 각 토핑 y +12 | 동일 |
| 3 | 스크롤 없음, 각 토핑 y **+12** (L 280 / R 366 / L 428) | `N=3까지 스크롤·세로 성장 없음` — +12 적용 여부 미기재. 클라이언트 확인 필요 |
| 4 이상 | 스크롤 발생, +12 없음(첫 토핑 y 268), 크림 1:1 성장 | 동일 |

#### 6.3 좌표

- x: 전체 템플릿(가로 324.3) 기준 Left 좌측 인셋 4 / Right 우측 인셋 4(x=160.3). 좌표 컨테이너는 크림이 아닌 템플릿 전체. Left↔Right 가로 -3.7은 파생값

- y (N ≥ 4): Left 268, 416, 564… / Right 354, 502, 650… (같은 side 세로 갭 -12, 스텝 +148)

#### 6.4 템플릿 고정 갭

| 구간 | 갭 |
| --- | --- |
| 체리 ↔ 첫 토핑 | -65 |
| 마지막 토핑 ↔ 접시 | -48 (side 무관) |
| 접시 ↔ 스크롤 인디케이터 (스크롤 시에만) | 정책서 **최소 16** / v7 **최소 -16** — 부호 불일치, 클라이언트 확인 필요 |

#### 6.5 토핑 규격·타입

- 토핑 = Img + Grouptag-Chip, 6타입(Left-1~3 / Right-1~3). 프레임 160×160 / Img 96×96(프레임 정중앙). 오버플로우 없음

- Chip 회전 없음, Z 항상 Img > Chip. Chip 기준점 = 프레임 중앙 하단 / Img 중앙 하단

- 변형 번호(1/2/3)는 목록 조회 응답 1회마다 랜덤 재부여(그룹 ID 고정 시드 아님). 리렌더·셀 재사용 시 재추첨 금지

### 9. G-001-Empty 온보딩 툴팁

- `+ 그룹 추가하기` 버튼 하단, 꼬리 위 방향. 가입 그룹 0건 자체가 조건(최초 1회 플래그 없음)

- 툴팁 외 영역 탭 시 닫힘, X 없음, 닫힘 상태 미저장 → 0건이면 재진입 시 재노출

- 딘·드롭섀도 없음
