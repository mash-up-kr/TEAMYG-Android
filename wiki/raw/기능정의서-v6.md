## v5 → v6 변경 요약

- **담당자/진행상황 컬럼 개편**: v5의 담당(디자인/iOS/AOS/Spring 역할 코드) 4컬럼 → v6는 담당자(인물)·진행상황(iOS 작업 중/안드 작업 중/디자인 작업/디자인 검수) 2컬럼. **단, 가변 항목이라 raw에는 제외**(위 안내 참고).
- **G-002(그룹 진입) 삭제**: v5의 G-002 행이 v6에 없음. 관련 흐름 재배선:
  - A-004(그룹 참여)·A-005(새 그룹 생성) 다음 단계: `G-002` → **`C-001`**.
  - C-001 진입 경로: `G-002` → **공백**(직접 진입).
  - G-001(그룹 목록) 다음 단계: `S-001, G-002, A-003` → **`S-001, A-003, C-001`**.
- **페이지 비고**: "에딧 모드 삭제" (아래 불일치 참고).
- 나머지 화면 정의(C 캔버스 계열, S 사이드바 계열, SY 시스템 계열)는 v5와 동일.

## 캡처 공백 / 원본 불일치

- **"에딧 모드 삭제" 비고 vs C-301~C-306 잔존**: 페이지 비고는 "에딧 모드 삭제"라 하나, 편집 모드 진입(C-301) 및 하위 편집 화면(C-302~C-306)은 v6 표에 그대로 존재. "에딧 모드"가 가리키는 대상(다른 편집 흐름?) 원본 확인 필요.
- **G-002 삭제 후 그룹 진입 로직**: 기존 G-002가 담당하던 "그룹 권한 유효 검증·강퇴/탈퇴 그룹 접근 차단" 예외처리가 어느 화면으로 흡수됐는지 v6 표에 미명시. C-001 직접 진입 시 권한 검증 위치 확인 필요.
- **SY-002 참조**: C-001 분기조건에 "없으면 SY-002로 자동 생성"이 있으나 SY-002 행은 표에 없음(SY-001-new가 실제 자동 생성 담당). v5부터 이어진 표기 불일치.
- **C-103-loading 기능명**: 원본 셀 공백. 편의상 "(로딩)"으로 표기.
