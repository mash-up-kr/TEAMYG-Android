## 파트 1 — 기술 검토 결과

### 배경 제거 (누끼) 퀄리티 ⭕

**iOS**

- 배경 제거 및 누끼 테두리 기능 모두 구현 가능

- 사물 꾹 눌러 선택하는 방식

- **박스 형식 제공은 검토** 🔺

**Android**

- 배경 제거 및 누끼 테두리 기능 구현 가능

- 촬영 환경에 따라 품질 편차 존재

- 인식 대상은 사용자가 선택만 가능 (자동 인식 불가)

- **사람 인식 부분은 확인 필요** 🔺

### 누끼 테두리 (Stroke) 효과 ⭕

- 구현 가능 확인

- 색상·곡률·두께는 고정값으로 제공

- 일부 자유도 부여 가능(색깔/두께 등)

### 사용자 정의 배경 ⭕

- 컬러 배경 및 사진 배경 모두 지원 예정

- 유저 자유 배치 가능

- 완성 결과물은 이미지로 변환 가능

- ⚠️ 위치 지정 템플릿은 MVP 제외

### 비회원 접근 및 작성자 표시 ⭕

- MVP: 접속 시마다 새로운 임시 코드값 부여

- 앱 삭제 시 코드 소멸

- 회원가입 없이도 임시 식별값으로 그룹·작성자 기능 관리

## 파트 2 — MVP 최종 확정

### ✅ 포함 기능

| 기능 | 내용 |
| --- | --- |
| 촬영 → 누끼 | 촬영 즉시 배경 제거. 수동 편집 없이 고품질 보장. 누끼 품질 기술 고도화 방향으로 진행 |
| 그룹 캔버스 | 친구들과 캔버스 공유, 누끼 스티커 올리기. 즉시성·내부 공유성 최우선. 실시간성 vs 공유 방식은 추가 확정 필요 |
| 배경 & 테두리 | 컬러·사진 배경 선택 + 누끼 테두리(Stroke) 효과. 유저 자유 배치 가능 |
| 갤러리 저장 | 결과물 이미지 변환 후 기기 갤러리 저장. 인스타 직접 연동 배제, 갤러리 경유 공유 |
| 작성자 표시 | 스티커 제작자 확인 기능 포함. 세부 우선순위는 전체 기능 확정 후 정의 |

### ❌ MVP 제외 항목

| 기능 | 제외 이유 |
| --- | --- |
| 자동 배치 | 기술적 문제로 MVP 완전 배제 |
| 위치 지정 템플릿 | 위치 배치 기능은 MVP에서 제외 |

### 🔄 추후 검토 항목

| 기능 | 내용 |
| --- | --- |
| 연속 사용 보상 🔥 | 7일 연속 참여 시 스티커 제공 등. MVP 이후 긍정적 검토 |
| 테두리 자유도 확장 | 곡률·색상·두께 조절. MVP는 고정값, 이후 변수 추가 검토 |
| 비회원 영구 식별 | 앱 삭제 후에도 유지되는 식별값 관리 방안 기술 검토 필요 |
