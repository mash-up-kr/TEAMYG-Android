    >
    > #### 그룹 목록 화면 진입시마다 재조회하는 방식 (N초 자동 재조회 X)

- ▶ 내가 정리한거..

    >
    >
    > #### 그룹의 닉네임 이름 설정 시 자동으로 계정의 닉네임 디폴트로 가져올 수 있음
    >
    > #### 그룹 참여 이후 G001 화면으로 이동
    >
    > #### 누끼 따는 지우개 및 테두리 크기 최소 최대는 추후 결정
    >
    > #### C001에서 바로 C101로 가는 것이 아니라 C101(카메라), C102(갤러리) 선택할 수 있는 플로우로 수정
    >
    > - C101로 갈 때 카메라 권한 없으면 카메라 권한 없는 UI
    >
    > - C102로 갈 때 갤러리 권한 없으면 갤러리 권한 없는 UI
    >
    > >
    > >
    > > - `카메라 권한이 없습니다, 권한을 허용해주세요` 와 같은 에러 화면 UI 필요
    > >
    > >     - 카메라 권한이 없습니다. (카메라 권한 요청 화면)
    > >
    > >         - 카메라 preview화면 안보이고 UI 띄우게
    > >
    > >     - 갤러리 접근 권한이 없습니다. (갤러리 접근 권한 요청 화면)
    > >
    > >     - 제한된 이미지 접근 권한이 없습니다. 
    > >
    > >         - 제한된 이미지 접근하려 하면 하면 사용자가 권한 재선택하도록 설정으로 이동시키는 플로우 필요하다
    > >
    > > - 설정하러 가기 추가 (권한 수정하도록 설정으로 가는 버튼)
    >
    > #### S001 Kakao, Apple 정도 로그인 어떤 방법 인지까지만 보여주는 걸로 (아이콘이어도 가능)
    >
    > #### 그룹 내에서 같은 닉네임 설정 가능

> > - 그룹 닉네임 기본값으로 **계정 닉네임 디폴트로 자동 입력**
>
> - 그룹 참여 완료 후 → **G001으로 이동**
>
> - 지우개/테두리 최소·최대 크기는 추후 결정
>
> - **C001 진입 플로우 수정**: 플러스 버튼 → 카메라/갤러리 선택 화면(C101/C102) 먼저 분기
>
>     - 카메라/갤러리 권한 없으면 권한 요청 UI (프리뷰 대신 표시)
>
>     - 설정으로 이동 유도
>
> - S001 로그인: 카카오/애플 **아이콘**으로 표시
>
> - 그룹 내 닉네임 **중복 허용**
