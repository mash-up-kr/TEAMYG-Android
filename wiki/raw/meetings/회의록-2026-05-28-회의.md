### **A. 사진 소스 정책** (오늘 결정 안건)

> **사전 기술 검토 요청 완료** — 각 플랫폼은 아래 항목에 대해 조사 결과를 회의 전 노션에 업로드
>
> - 당일 앨범 사진만 불러오기 기능 구현 가능 여부
>
> - 가능하다면 MVP 포함 여부

#### **둘 다 + 갤러리 "오늘 사진" 디폴트 (기간제한 O)** ← 인터뷰 추천 💜

- 안드

    - MVP로 시스템 갤러리 픽커를 사용하여 이미지 선택 후 날짜를 체크하는 방식으로 “오늘 사진” 구현 가능

    - 차후 갤러리 커스텀할 경우 → 사진 자체를 불러올 때부터 필터링 가능

- iOS

    - 앨범에서 당일 찍은 사진만 필터링 가능

### **B. 캔버스 편집 권한 정책** (참가자 우려 반영)

- ▶ 추후 구현 사항들

    **현재 기준**: n초 전 기준으로 다른 사용자가 이동시킨 사진의 위치를 보여주는 방식

    **① 실시간 편집자 표시 여부** *🔺*

    현재 편집 중인 유저를 Discord의 "접속중" 표시처럼 노출할지 여부

    - 디자인 의도: 다른 그룹원이 사진 업로드 중일 때 캔버스 상단에 칩/띠 형태로 실시간 상태 노출 예정

    - 감지 시작 시점: 카메라 또는 갤러리 진입 시점부터 상태 전송 가능한지 확인 필요 (누끼 실패 후 재시도 포함)

    - **2단계 상태 표시 방식 (검토 필요)**

        - 1단계: 카메라/갤러리 진입 → 누끼 → 테두리 편집 단계 → 상단 칩만 노출

        - 2단계: 캔버스에 객체 올리고 위치 조정하는 단계 (C-105) → 상단 칩 + 해당 객체 주변 점선 글로우 노출
