## 5) 첫 업로드 부재 이슈

> 💡 
>
> **매일 빈 캔버스로 시작 → 첫 타자만 부담을 짐 → 아무도 안 올림**
>
> 목표: 올릴 게 없어도 올리게 만들기. 푸시는 안 씀

### 왜 안 올렸나

- 올릴 사진이 없음 (3시~3시에 찍은 사진만 가능, 출근 사진 정도가 전부)

- 첫 타자가 민망함 (나만 하는 느낌). 예쁜 걸 올려야 할 것 같은데 나한테 예쁜 게 없음

- 그룹과 무드가 안 맞으면 더 올리기 어려움 

- 들어올 계기가 없음. 푸시는 많으면 그냥 끔

### 제안 방향

- **A. 단톡 공유**: 텍스트 올린 직후 「단톡에 알리기」 → 쓴 텍스트 + 캔버스 링크가 카톡으로

    - 앱 알림은 무시해도 친구 말은 무시하기 어려움

    - **결정: 기각**

- **B. C-001 Empty state 개편** (G-001 Empty Case와 별개)

    - 지금: 회색 캔버스 + 안내 문구

    - 아이디어: 더미 사진(예쁜 것 + 일부러 별로인 것 둘 다)을 깔아서 「뭐든 올려도 된다」는 걸 보여줌 / 쌓기 버튼 위계 높이기. DSN-A이 G-001에서 쓴 더미 이미지가 좋았다는 의견

    - AOS-A 의견: 예전에 하다 만 달력·땅 같은 샘플 배경화면 형태의 가이드라인. 화면을 못 올리는 이유가 아무것도 없어서이기 때문 (템플릿이라기보다 이미지 하나)

    - 몇 개를 어떻게 넣을지(랜덤 여부)는 미정

    - 공수: 무난 (아마) → **추진**

- **C. 홈 화면 위젯 (미리보기형)**

    - 위젯에서 다 보고 끝나지 않도록, 사진은 가리고 활동 정보만 보여줌

    - 최근 올라온 사진은 모자이크 / 블러 / 실루엣 중 하나로 처리 + 올린 사람 닉네임 + 시간대 (예: 「OO님이 오전 9시쯤 쌓음」)

    - 앱 자체에 진입을 안 하는 문제의 해결책. 한계: 누군가 올린 뒤에야 의미가 생김 (첫 타자 자체는 B가 담당)

    - 공수: 매우 큼 → 만약 한다면 **iOS만**, 1:1 정사각형 사이즈, 그룹 전체를 통틀어 가장 최근에 올라온 토핑 1개 노출 (그룹명, 닉네임, 타임스탬프, 토핑)

        - 그룹별 위젯은 같은 사이즈를 여러 개 못 까는 제약이 있을 것 같아 어려움 (카톡 위젯 확인)

        - Android는 개발 난이도 때문에 제외. 일단 긍정적 검토 단계, 당장 확정은 아님

    - **결정: 추진 (C는 iOS만)**

- **D. N개 올라오기 전까진 블라인드 상태**

    - 예쁘게 꾸미고 싶어하는 사용자에게는 블라인드가 풀린 순간 엉망이 되어 당혹스러운 업데이트가 될 수 있음

    - **결정: 기각**

## 6) 수동 삭제 가능 여부 (CSAE 대응)

- 배경: 플레이스토어 카테고리를 소셜로 바꾸면서 아동 안전 표준(CSAE) 페이지를 게시해야 함. 어드민 화면은 없어도 되고 DB/스토리지에서 직접 처리할 수 있으면 충분

- 서버 확인 결과

    1. 특정 사진을 DB·스토리지(이미지 파일)에서 직접 삭제 → **가능** (AWS 서버에서 삭제)

    2. 삭제 시 병합된 캔버스·갤러리 저장본 반영 → 이전 캔버스는 조회할 때마다 서버에서 가져오므로 삭제하면 전날 캔버스에서 안 보임. **이미 갤러리에 저장된 것은 반영 불가**

    3. 특정 계정 정지/삭제 → **임의로 가능**

    4. 정지된 계정의 재가입 차단 → **현재는 불가**. DB에서 삭제하지 않고 정지 컬럼을 추가하는 방식이면 가능할 듯 (추가 개발 필요)

    5. 신고 접수 후 삭제까지 → **24시간**으로 정책 기재

    6. 삭제 작업 담당 → **SPR-A** (서버)

### 왜 안 올렸나

- 올릴 사진이 없음 (3시~3시에 찍은 사진만 가능)

- 첫 타자가 민망함 (나만 하는 느낌)

- 들어올 계기가 없음 (누가 말 걸어주면 들어올 텐데)

- 푸시는 많으면 그냥 끔

### 제안 방향

- **A. 단톡 공유**: 텍스트 올린 직후 "단톡에 알리기" → 쓴 텍스트 + 캔버스 링크가 카톡으로

    - 앱 알림은 무시해도 친구 말은 무시하기 어려움

- **B.** **C-001 Empty state 개편** (G-001 Empty Case와 별개)

    - 지금: 회색 캔버스 + 안내 문구

    - 아이디어: 더미 사진 깔아두기 / 쌓기 버튼 위계 높이기 / 더 있으면 추가

    - 공수: 무난 (아마) → 도전?

- **C.** **홈 화면 위젯 (미리보기형****)**
