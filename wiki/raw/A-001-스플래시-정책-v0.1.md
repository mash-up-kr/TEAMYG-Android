# 1. 스플래시 애니메이션

## 에셋

- 원문에 **로티 파일 링크**("바로가기 →" 하이퍼링크)가 걸려 있다. 링크 대상 URL은 스크린샷에 노출되지 않아 수집되지 않았다.
- 첨부 썸네일 캡션은 `Lottie-Logo`. 로고는 **`Parfait`** 글자를 적색으로 쓴 형태다.

## 전체 규격

- **총 3.5초 / 60fps**.

## 타임라인

| 구간 | 동작 |
| --- | --- |
| 0.5s부터 0.2s 간격 | 글자 **7개**(`P` `a` `r` `f` `a` `i` `t`) 순차 팝인 — scale 1.1 → 1, opacity 0 → 100, **spring** |
| 2.1s ~ 3.0s | 하단 획 **왼쪽 → 오른쪽 드로잉** — trim path 0 → 100% |
| 3.0s ~ 3.5s | **홀드 후 루프** |

- ⚠️ **스플래시 최소 노출 시간 3.5s 보장**. 짧으면 애니메이션이 중간에 잘린다.

## 배치

- **중앙 정렬**.

# 원문에 명시되지 않은 사항

- **로티 파일명**이 기재되지 않았다(`Lottie-Logo`는 첨부 썸네일의 캡션이다). 같은 날짜의 공통 로딩 정책이 파일명 2종을 명시한 것과 대비된다.
- **로고 에셋의 크기**가 기재되지 않았다(공통 로딩은 44x44를 명시).
- **스플래시 배경**(색·이미지)이 기재되지 않았다. 이 문서는 로고 애니메이션만 다룬다.
- **라이트·다크 대응 여부**가 없다. 에셋이 1종만 언급된다.
- **3.5s 이후의 전이 대상**이 없다. 기능정의서상 A-001은 토큰 유효 시 G-001, 미로그인 시 A-002로 분기하나 이 문서는 분기를 다루지 않는다.
- 로고 문자열이 `Parfait`이나, 이것이 **정식 제품명인지**는 이 문서만으로 확정되지 않는다.
