## 본문 (원문 그대로)

#### 본문 `6837:13448`

```text
[토핑 중앙 정렬 & 각도 가이드 / 스냅]

■ 공통
- 적용: 토핑 이동·회전 중에만 (한 손가락 드래그 + 두 손가락 핀치 중 위치 이동·회전)
- 최초 업로드 배치 / 수정 공통
- 토핑은 이미지, 텍스트 공통
-※ 테두리 설정 패널 열림 시 사진이 화면 가운데로 자동 이동하는 동작은 적용 제외.
사용자 조작이 아니라 시스템 이동이므로 가이드 노출·스냅·햅틱 모두 발생하지 않음
- 좌표 = 토핑 중심점, 캔버스 대비 0~1 상대값

■ 1. 위치 가이드 (옐로우 실선)
- 캔버스 정중앙 세로선 + 가로선 2줄, 캔버스 끝까지, 위치 고정
- 세로선: |x − 0.5| × 캔버스 너비 ≤ 6pt
- 가로선: |y − 0.5| × 캔버스 높이 ≤ 6pt
- 가로·세로 독립 판정, 둘 다 충족 = 정중앙 (두 선 동시 노출)
- 조건 충족 → 가이드 노출 + 해당 축 0.5로 스냅 + 햅틱 1회
- 6pt는 시작값, 빌드 확인 후 조정 가능성 있슴!!

■ 2. 각도 가이드 (민트 점선)
- 회전 각도가 0° / 90° / 180° / 270° 기준 ±3° 이내 → 가이드 노출 + 해당 각도로 스냅 + 햅틱 1회
- 0°/180° → 수평선, 90°/270° → 수직선
- 토핑 중심을 지나 캔버스 끝까지 가로지름 (토핑 크기와 무관)
- 토핑 이동 시 선도 토핑을 따라 이동 (위치 가이드와 달리 고정 아님)
- ±3°는 시작값, 빌드 확인 후 조정

■ 동시 적용
- 위치 스냅과 각도 스냅은 독립이며 동시에 걸릴 수 있음
- 정중앙 + 수평/수직 각도 동시 충족 시 위치 가이드(옐로우 실선)와
각도 가이드(민트 점선) 모두 노출, 민트 점선이 옐로우 실선 위에 표시
- 햅틱: 축·각도별 진입마다 1회, 같은 프레임에 동시 진입이면 1회로 합침

■ 해제
- 해제 판정은 손가락 기준 (스냅 중 토핑은 고정 상태)
- 임계값 밖 → 해당 스냅 해제 + 해당 가이드만 사라짐
- 손 뗌 → 가이드 모두 사라짐, 스냅된 값(위치·각도)으로 저장

■ 애니메이션
- 노출: Fade In 100ms, ease-out
- 사라짐: Fade Out 150ms, ease-out
- 위치 가이드는 위치 이동 없음, 각도 가이드는 토핑을 따라 이동 (페이드만 적용)
- 토핑이 스냅 위치로 붙는 모션: 80~100ms

■ 레이어
[초기 배치] 이동 중 토핑(삭제 버튼 없음) > Edit-Area (텍스트 토핑은 Edit-Area 없음)
> 각도 가이드(민트 점선) > 위치 가이드(옐로우 실선)
> 본인의 다른 토핑 > 딤 > 나머지 토핑 > 배경
[수정]      이동 중 토핑 + 삭제 버튼
> 각도 가이드(민트 점선) > 위치 가이드(옐로우 실선) (Edit-Area 미노출)
> 본인의 다른 토핑 > 딤 > 나머지 토핑 > 배경
```
