# 1. 최대 렌더링 영역 (Max Bounding Box)

- **최대 너비**: `Device Width − 40px` (좌우 패딩 각 20px).
- **최대 높이**: `Device Height − (상단바 영역 + 10px) − (하단 버튼 영역 + 16px)`.

---

# 2. 원본 이미지 비율에 따른 조건부 분기 처리

## Case A: 가로가 꽉 차는 경우 (가로형 및 정방형 이미지)
- **적용 조건**: 렌더링 시 이미지의 **너비가 '최대 너비'에 먼저 도달**하는 경우.
- **노출 정책**: 별도의 배경 컨테이너나 테두리 없이 **원본 이미지 단독 노출**.
- **사이즈 및 여백**: 좌우 패딩 20px을 지키며 **너비 100%로 렌더링**.

## Case B: 세로가 꽉 차는 경우 (세로형 이미지 — 너비가 남을 때)
- **적용 조건**: 렌더링 시 이미지의 **높이가 '최대 높이'에 먼저 도달**하여 좌우 너비가 남는 경우.
- **노출 정책**: 빈 공간을 채우는 **흰색 배경의 컨테이너 생성 및 테두리 적용**.
- **컨테이너 규격**: 너비는 `Device Width − 40px`(가득 채움), 높이는 **렌더링된 이미지의 높이와 동일**하게 설정.
- **이미지 정렬**: 생성된 흰색 컨테이너 내부에서 이미지를 **좌우 정중앙(Center)** 으로 배치.
- **테두리(Border) 처리**: 이미지 자체가 아닌, **흰색 컨테이너 외곽선에만 `Gray-500` 1px 스트로크** 적용.

# 3. 참고 이미지 (목업)

세로형 이미지 렌더링 비교 목업:
- **좌**: 세로형(Case B) — 흰색 컨테이너가 좌우 빈 공간을 채우고, 이미지가 중앙 정렬. 컨테이너 외곽선에 Gray-500 1px.
- **우**: 정방형(Case A) — 너비 100%로 단독 노출, 배경 컨테이너·테두리 없음.
