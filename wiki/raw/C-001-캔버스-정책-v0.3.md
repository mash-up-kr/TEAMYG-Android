### 2. 반응형 정책

**세로 모드 전용. 태블릿·가로모드 미고려.**

#### 2.1 우선순위

1. `Canvas-Area`  **9:16 비율 무조건 유지** (가로 9 : 세로 16 — 세로 고정)

1. 상단 gap(탑바 ↔ 캔버스)과 하단 gap(메뉴 ↔ 홈 인디케이터)은 **항상 동일**, **최소 12px 보장**

1. 좌우 패딩 **20px 유지** (가능한 한도 내에서)

#### 2.2 실측값 (375×812)

| 항목 | 값 |
| --- | --- |
| 좌우 패딩 | 20px |
| 상단 gap (Top Bar 하단 108 → Canvas 상단 124) | 16px |
| 하단 gap (Canvas 하단 764 → Home Indicator 780) | 16px |
| Canvas 폭 / Canvas-Area 높이 | 335 / 596 |

#### 2.3 예외

세로 공간이 부족한 기기에서는 **최소 gap 12px를 우선 보장**하기 위해 캔버스가 축소되고 좌우 패딩이 20px보다 커진다 → 캔버스가 탑바보다 좁아 보일 수 있음.

#### 2.4 내부 요소 스케일링

캔버스 내부의 모든 요소는 캔버스 크기 변화에 **비례하여 동일한 비율로 스케일**된다.

### 7. 배경 레이어 정책 (v0.3 전면 교체)

> 🚫 
> **폐기**: 구 v0.2 「2. Background Blur 정책」 — 배경 종류와 무관하게 Black-25 / Uniform / Blur 4 도형을 상시 적용한다는 규칙은 **삭제한다.**
>
>

**현행**: 화면 전면(375×812)에 **Dot Grid** 배경을 사용한다.

- 도트 간격 22px (x·y 동일), 도트 크기 2×2

- 캔버스 영역 바깥의 앱 배경 역할

- 캔버스 자체 배경(단색/이미지)은 `Canvas-Area > Background` 레이어가 담당하며, 그 위에 덮이는 상시 블러 도형은 **없다**

- 유일하게 사용되는 오버레이는 2뎁스 메뉴 열림 시의 `Dim` (5.1)
