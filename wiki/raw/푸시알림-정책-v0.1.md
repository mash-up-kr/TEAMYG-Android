### 1. 개요

#### 1.1 목적

파르페에 푸시 알림을 도입한다. 목적은 두 가지다.

1. **그룹 활동 인지** — 그룹원이 토핑을 쌓았다는 사실을 즉시 알린다.

1. **마감 사이클 인지** — 캔버스가 매일 03:00 KST에 마감된다는 서비스 구조상, 마감 전에 참여할 기회를 안내한다.

#### 1.2 확정 사항 요약

| 항목 | 결정 |
| --- | --- |
| 알림 종류 | P-01 토핑 등록<br>P-02 오전 리마인드 <br>P-03 저녁 리마인드 |
| 토핑 알림 발송 방식 | **개별 발송, 상한 없음** |
| 리마인드 발송 시각 | **10:00 / 20:00 KST** |
| 권한 요청 시점 | **첫 그룹 참여(A-004)·생성(A-005) 완료 직후**   |
| 수신 거부 수단 | **OS 시스템 알림 설정 only**   |
| 시간대 기준 | **서버 KST 고정**   |

### 2. 알림 종류 정의

#### 2.1 P-01 — 토핑 등록 알림

| 항목 | 내용 |
| --- | --- |
| 성격 | **정보성** (그룹 내 활동 발생 사실 통지) |
| 트리거 | 그룹원이 C-106에서 토핑 배치를 **확정 저장한 시점** |
| 발송 대상 | 해당 그룹의 **본인을 제외한 전체 그룹원** |
| 발송량 | **1 업로드 = 1 발송.** 묶음·상한·쿨다운 없음 |
| 시간 제한 | **없음** (24시간 발송 가능. 정보성 메시지) |
| 진입 화면 | **C-001** (해당 그룹의 해당 일자 캔버스) |

##### 문구


```plain text
제목: {그룹명} 파르페에 체리 얹을 타이밍!
본문: {그룹 내 닉네임}님이 새 토핑을 쌓았어요
```

- 발송 큐 처리 중 작성자가 탈퇴·그룹 나가기한 경우 → 본문을`누군가 새 토핑을 쌓았어요` 로 대체

#### 2.2 P-02 — 오전 리마인드 (10:00 KST)

| 항목 | 내용 |
| --- | --- |
| 성격 | **정보성**(마감 사이클 안내)으로 설계 |
| 트리거 | 스케줄러, 매일 10:00 KST |
| 발송 대상 | 가입 그룹 **1개 이상** 보유 + 알림 권한 허용 + 유효 토큰 보유 이용자 |
| 진입 화면 | **G-001** |

##### 문구

```plain text
제목: 새벽 3시에 오늘의 새 캔버스가 열렸어요
본문: 오늘의 첫 토핑을 쌓아볼까요?
```

#### 2.3 P-03 — 저녁 리마인드 (20:00 KST)

| 항목 | 내용 |

| 성격 | **정보성**(마감 사이클 안내)으로 설계  |

### 3. 권한 정책

#### 3.1 요청 시점

- **A-004(그룹 참여) 또는 A-005(그룹 생성) 완료 직후, G-002 진입 전 1회.**

#### 3.2 요청 전 안내

```plain text
제목: 그룹원이 토핑을 쌓으면 알려드릴까요?
본문: 새 토핑 소식과 캔버스 마감 안내를 받을 수 있어요.
      알림은 언제든 기기 설정에서 %끌 수 있어요.
버튼: [알림 받기]  [나중에]
```

- `[알림 받기]` → OS 권한 다이얼로그 호출

- `[나중에]` → OS 다이얼로그 호출하지 않고 G-002 진입. **재노출 없음** (v0.1 기준)

#### 3.3 거부 시 동작

- 서버에 토큰이 등록되지 않으므로 **발송 시도 자체를 하지 않는다.**

- 앱 내에서 권한 재요청 배너·모달을 띄우지 않는다.

- 이용자가 스스로 켜려면 **기기 설정 > 알림 > 파르페**에서 허용한다. 이 경로는 S-004(약관 및 개인정보 처리방침) 화면과 개인정보처리방침 본문에 안내한다.

#### 3.4 수신 거부(옵트아웃)

- **OS 시스템 알림 설정에서 전체 끄기**가 유일한 수단이다. 앱 내 알림 설정 화면·개별 토글은 MVP 범위 외.

### 4. 딥링크 및 클릭 시나리오

```plain text
[P-01 토핑 알림]
푸시 탭 → (앱 상태 분기) → G-002(권한 검증) → C-001 (해당 date 캔버스)
                                └ 그룹 나가기 등으로 접근이 안되거나 그룹 삭제된 경우 → G-001 + 토스트 (E-04)

[P-02 / P-03 리마인드]
푸시 탭 → (앱 상태 분기) → G-001
```

#### 4.2 앱 상태별 동작

| 앱 상태 | 동작 |
| --- | --- |
| **종료(Cold start)** | A-001 스플래시 → 토큰/버전 체크 → **딥링크 목적지로 직행** (G-001을 거치지 않음). 딥링크는 세션 저장 후 1회 소비 |
| **미로그인 상태에서 탭** | **딥링크 폐기.** A-001 → A-002 → A-003 → 로그인 완료 후 **G-001 일반 진입** |
| **강제 업데이트 대상** | 스토어 이동 안내 우선. 딥링크 폐기 |
| **백그라운드** | 현재 스택 위에 목적지를 push. 뒤로가기 시 직전 화면 복귀 |
| **포그라운드 · 해당 그룹 C-001 체류 중** | **OS 배너 억제.** 기존 C-001 **상단 알림 띠**로 대체 (서비스 공통 규칙 2절 동기화). **운영 확인 결과 미동작 — OS 푸시가 그대로 오고 알림 띠는 안 뜸. 운영 백로그 등록(2026-09-20)** |
| **포그라운드 · 그 외 화면** | 인앱 배너 노출. 탭 시 동일 딥링크 처리 |
| **토핑 올리기(C-101~C-106) 또는 본인 토핑 수정(C-305·C-306) 중** | **인앱 배너 억제.** 작업 중 이탈 방지. 알림은 알림센터에만 적재. **운영 확인 결과 본인 토핑 수정 중에도 푸시가 옴(미동작) — 운영 백로그 등록(2026-09-20)** |

#### 4.3 도착 후 예외

- **날짜가 넘어간 경우**: 푸시의 `date` 기준 캔버스로 진입한다. 오늘자로 리다이렉트하지 않는다. 해당 캔버스가 이미 마감(03:00 경과)됐어도 그 일자의 C-001로 진입한다(마감 캔버스는 편집 불가).

- **해당 토핑이 신고·삭제된 경우**: 캔버스는 정상 진입하되 토스트 `해당 토핑은 삭제됐어요`.

### 5. 예외 케이스

| # | 케이스 | 처리 |
| --- | --- | --- |
| E-01 | 본인이 올린 토핑 | 본인에게 발송하지 않음 |
| E-02 | 수신자가 알림 권한 미허용 | 토큰 없음 → 발송 시도 없음 |
| E-03 | 수신자가 해당 그룹을 나간 뒤 발송 큐 소비 | **발송 취소** (발송 직전 대상 재검증) |
| E-04 | 그룹이 삭제됨(마지막 1인 나가기)<br>혹은 푸시알림 도착 후 그룹에서 본인이 나감 | 발송 취소. 이미 발송된 건은 탭 시 **G-001 + 토스트**  `참여 중이 아닌 그룹이에요` |
| E-05 | 작성자가 업로드 직후 탈퇴·나가기 | 문구를 `누군가 새 토핑을 쌓았어요`로 치환 후 발송 |
| E-06 | 03:00 마감 경계에서 발송/도착 | 푸시의 `date` 기준, 그 일자의 **C-001**로 진입 (마감 캔버스는 편집 불가) |
| E-07 | 토핑이 신고·삭제된 뒤 탭 | 캔버스는 진입, 토스트 `해당 토핑은 삭제됐어요` |
| E-08 | 12인 동시 업로드 | 개별 발송 유지. 수신자당 최대 11건. 서버는 큐 순차 처리(초당 발송량 제한만 적용) |
| E-09 | FCM/APNs 장애·지연 | **TTL 적용** — P-01은 6시간, P-02/P-03은 1시간. TTL 초과분은 폐기. 리마인드가 **21:00 이후 도착하는 것을 금지** |
| E-10 | 토큰 만료·무효 | 응답 코드 기준 서버에서 토큰 삭제. 재로그인 시 재등록 |
| E-11 | 다른 기기에서 로그인 | 구 토큰 즉시 폐기 (5절) |
| E-12 | 앱 삭제 | OS가 토큰 무효화 → E-10 경로로 정리 |
| E-13 | 탈퇴 후 재가입 | 신규 이용자 취급. 토큰 신규 등록, 권한 요청도 3.1 규칙대로 다시 발생 |
| E-14 | 해외 체류 이용자 | **KST 고정 발송.** 로컬 시간대 추종하지 않음 (마감 03:00 KST 고정 정책과 정합). 처리방침·약관에 명시 |
| E-15 | 앱 포그라운드, 해당 캔버스 열람 중 | OS 배너 억제 → 상단 알림 띠로 대체 (운영 미동작 — 백로그 등록) |
| E-16 | 토핑 올리기(C-101~C-106) 또는 본인 토핑 수정(C-305·C-306) 중 | 인앱 배너 억제, 알림센터에만 적재 (운영 미동작 — 백로그 등록) |
| E-17 | 미로그인 상태에서 푸시 탭 | 딥링크 폐기. 로그인 완료 후 G-001 일반 진입 |
| E-18 | 강제 업데이트 필요 | 스토어 이동 우선, 딥링크 폐기 |
