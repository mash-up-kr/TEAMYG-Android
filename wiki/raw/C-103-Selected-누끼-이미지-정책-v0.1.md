# 1. 캔버스(Canvas) 생성 기준 (데이터 영역)

이후 편집(영역 채우기, 테두리 추가)을 원활하게 하기 위해, **단순히 객체만 잘라내지 않고 여백을 포함한 '캔버스'를 생성하여 C-105까지 동일한 스케일로 전달**한다.

- **기준 영역**: C-103-Selected 화면에서 시스템이 인식한 대상 객체의 **최소 바운딩 박스**(타이트한 점선 영역).
- **안전 여백(Safe Margin) 추가**: 객체 바운딩 박스를 기준으로 **상하좌우 +20%**(또는 지정된 고정 픽셀)의 여백 공간을 추가하여 최종 캔버스를 생성.
- **예외 처리 (사진 가장자리 객체)**: 대상이 원본 사진의 끝에 위치하여 지정한 여백(20%)만큼 뻗어나갈 사진 데이터가 없는 경우, 부족한 공간은 **투명 픽셀(Alpha 0%)로 강제 확장**하여 캔버스 크기를 동일하게 유지.

---

# 2. 화면 노출 기준 (UI 렌더링)

생성된 캔버스를 각 화면(**C-103 ~ C-105**)에서 사용자에게 보여주는 기준.

## 2.1 최대 렌더링 영역 (Max Bounding Box)
- **최대 너비**: `Device Width − 40px` (좌우 패딩 각 20px).
- **최대 높이**: `Device Height − (상단 UI + 10px) − (하단 UI + 16px)`.

## 2.2 스케일링 및 정렬
- 캔버스 전체(**객체 + 여백 포함**)의 가로세로 비율을 **100% 유지**하며, 최대 렌더링 영역 안에 **Aspect Fit (`object-fit: contain`)** 방식으로 맞춤.
- 렌더링된 이미지는 화면의 남는 여백 안에서 **정중앙(Center-Horizontal, Center-Vertical)** 에 배치.
