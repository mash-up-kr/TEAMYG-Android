# 1. 닉네임 생성 정책

## 1.1 초기 자동 생성 규칙 (v0.2 신규)
- 계정 생성 시 **1회**, **형용사/동사 + 파르페 재료**를 랜덤 조합해 **앱 닉네임을 자동 부여**함.
- 조합 형식은 형용사/동사와 재료를 **공백 없이 붙여씀** (예: `녹는딸기`, `몽글한푸딩`).
- 생성된 닉네임은 계정 생성 즉시 저장되며 **이후 재계산되지 않음**.
- 조합 단어 목록(**형용사/동사 100개, 파르페 재료 30개**)은 **노션 참고**. <!-- 원본에서 노션 문서로 하이퍼링크 -->

## 1.2 허용 문자 규칙
- **한글, 영문, 숫자, 공백(스페이스바)** 만 입력할 수 있음.
- 특수문자나 이모지 입력 불가.

## 1.3 글자 수 제한 규칙
- **최소 1자 ~ 최대 15자**까지 입력 가능함.
- 글자 사이에 들어가는 **공백(띄어쓰기)도 동일하게 1글자로 카운트**함.

## 1.4 공백(띄어쓰기) 제한 규칙
- 닉네임의 **맨 앞과 맨 뒤에는 공백을 넣을 수 없음**.
- 글자 사이에 넣는 공백은 **오직 1칸만 허용**하며, **연속 공백은 제한**함.

# 2. 입력 예시 가이드

## 2.1 통과 케이스
- `열다섯글자열다섯글자열다섯글자` — 공백 없이 15자 충족으로 가능.
- `홍 길동` — 글자 사이에 공백이 1칸만 들어가므로 가능.

## 2.2 불통과 케이스
- `            ` — 공백으로만 채운 닉네임이므로 불가능.
- ` 길동` 또는 `길동 ` — 닉네임 시작이나 끝에 공백이 포함되어 불가능.
- `홍  길동` — 글자 사이에 공백이 2칸 연속으로 들어가서 불가능.
- `열 다 섯 글 자 열 다 섯 글 자 열 다 섯 글 자` — 15자를 초과해 불가능.
