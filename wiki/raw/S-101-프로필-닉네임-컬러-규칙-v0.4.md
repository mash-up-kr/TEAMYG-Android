# 1. 프로필 이미지 정책

- 프로필 사진은 **닉네임 첫 글자가 들어간 원형 프로필 이미지(Nametag-Chip)** 로 노출.
- Nametag-Chip는 총 **6개 컬러**(연핑크, 진핑크, 체리, 그레이, 멜론, 푸딩)별로 **각 2개 타입** 존재 → **총 12종**.
- 계정당 **12종 중 1종 랜덤** 배정.

---

# 2. Nametag-Chip 타입 고정 정책

- 타입은 **계정 생성 시 1회 랜덤 배정**, 이후에는 변경되지 않는다.
- **동일한 닉네임을 사용하는 사용자라도 계정이 다르면 서로 다른 타입**이 배정될 수 있다.
- 한 번 배정된 타입은 **모든 화면에서 동일하게 유지**되며, 앱 재접속·그룹 변경에도 변하지 않는다. 별도의 타입 변경 기능이 추가되지 않는 한, 계정이 유지되는 동안 동일 타입을 사용한다.

## 예시 (실명 마스킹 · 더미)

- 계정 A (닉네임 `홍씨`) → **Type 1** 배정 → 모든 화면에서 Type 1 유지
- 계정 B (닉네임 `홍씨`) → **Type 8** 배정 → 모든 화면에서 Type 8 유지
- 즉, **닉네임이 같아도 사용자(계정)가 다르면** 서로 다른 Nametag-Chip과 토스트 닉네임 컬러를 가질 수 있다.

---

# 3. 토스트 알림 닉네임 컬러 매핑 정책

- 공용 캔버스에서 액션 발생 시, 동접 중인 그룹원에게 토스트 알림이 뜬다.
- **토스트 속 닉네임 텍스트** 컬러는 유저의 **Nametag-Chip 타입에 따라 아래와 같이 강제 매핑**된다.

| 컬러 (타입) | 텍스트 컬러 |
| --- | --- |
| 연핑크 (Type 1, 2) | Cherry-200 |
| 진핑크 (Type 3, 4) | Cherry-300 |
| 체리 (Type 5, 6) | Cherry-400 |
| 그레이 (Type 7, 8) | White |
| 멜론 (Type 9, 10) | Melon |
| 푸딩 (Type 11, 12) | Pudding |

# 4. Nametag-Chip Default 상태 추가 (v0.4 신규)

- 아래 경우에는 12종 타입 대신 **Default** Nametag-Chip을 노출한다.
  - **탈퇴한 그룹원**의 Nametag-Chip을 노출해야 하는 경우
  - Nametag-Chip **불러오기에 실패한 경우** 등
- 원문: "Nametag-Chip에 문제 생기면 다 Default로 노출해주시면 됩니다" — 즉 위 2건은 열거 예시이고, **Nametag-Chip을 정상 결정할 수 없는 모든 상황이 Default 대상**이다.

## 예시 이미지에서 읽히는 Default 표현

- **Nametag-Chip**: 밝은 회색/흰색 원형에 닉네임 첫 글자 대신 **`-`(대시) 글리프**.
- **Toast > Username**: 닉네임 자리를 문구로 대체 — "**알 수 없는 사용자가** 59분 전에 쌓았어요". 즉 Default에서는 `{닉네임}님이` 대신 `알 수 없는 사용자가` 형태를 쓴다.
- **Grouptag-Chip**: 닉네임 자리에 "**알수없음**" 표기(예: `알수없음  59분전`).
- 이미지 주석: "**탈퇴했으면 무조건 이름 알수없음임**".

## 원문에 명시되지 않은 사항

- Default 상태의 **컬러 토큰 이름**(칩 배경·테두리, 토스트 닉네임 텍스트)은 문서에 기재되지 않았다. 예시 이미지상 회색 계열로만 확인된다.
- Default 문구가 화면별로 "알 수 없는 사용자" / "알수없음" 두 가지로 나타나는데, 각각이 어느 컴포넌트에 고정되는지는 예시로만 제시되어 있다.
