#### 1. 배경 & 문제 정의

- 현 상태: 수신 거부 수단이 **OS 전체 끄기뿐**. 그룹원 활동 알림은 1건당 1발송·상한 없음 → 12인 그룹이면 수신자당 최대 11건이 연달아 온다.

- 내부 테스트 관찰: **푸시가 없으면 앱 재진입이 거의 일어나지 않음** → 리텐션이 푸시에 크게 의존.

- 리스크: 알림에 짜증난 유저가 **OS에서 전체 차단 1회 → 영구 이탈**. 복구 경로 없음.

- 팀 내부 의견: 그룹원 활동 알림을 아예 끄기보다 **개수를 줄이고 싶다**.

- 정책 목표: **"전체 끄기"를 유저가 선택할 이유 자체를 없앤다.**  리마인드는 끌 수 있게 하고, 그룹원 활동 알림은 끄는 대신 모아 받을 수 있게 한다.

#### 2. 핵심 원칙

| # | 원칙 | 근거 |
| --- | --- | --- |
| P-1 | **앱 내에 "전체 끄기" 토글을 두지 않는다** | 전체 차단은 OS 설정에만. 유저 눈앞에 "전부 끄기" 선택지가 아예 없음 (v0.2 유지) |
| P-2 | **그룹원 활동 알림은 끄는 대신 받는 방식만 고른다** | 리텐션 엔진이라 앱 안에서 끄는 수단을 주지 않고, 개수를 줄이는 수단(모아 받기)으로 대신한다 |
| P-3 | **기본값은 현행과 같다** — 오늘의 캔버스 알림 ON, 알림 모아 받기 OFF | 기존 유저 체감 변화 없음. 직접 바꾼 사람만 반영 |
| P-4 | **UI에 묶음 주기(10분)를 노출하지 않는다** | '10분'이라는 숫자가 "10분마다 알림이 온다"로 읽혀 오히려 잦게 느껴질 수 있음. "알림이 많아지면 모아서 한번에 보내드려요"로만 안내 |

#### 3. 화면 구성 (S-105)

**토글 2개 · 앱 내 전체 토글 없음**.

```plain text
[상단 바]          <  알림 설정
[OS 알림 꺼짐 안내] ← OS 알림이 꺼져 있을 때만 (3.4)
[토글 1]           오늘의 캔버스 알림
[토글 2]           알림 모아 받기
```

##### 3.1 토글 1 — `오늘의 캔버스 알림`

| 항목 | 내용 |
| --- | --- |
| 보조 문구 | 아침 10시 오픈, 오후 8시 마감 알림을 보내드려요 |
| 포함 푸시 | **P-02**(오전 10:00) + **P-03**(저녁 20:00) |
| 기본값 | **ON** |
| OFF 시 | P-02·P-03 발송 대상에서 제외 (상위 E-23) |
| 전환 | 즉시 반영, 확인 없음 |

##### 3.2 토글 2 — `알림 모아 받기`

| 항목 | 내용 |
| --- | --- |
| 보조 문구 | 그룹원 활동이 많아지면 모아서 한번에 보내드려요 |
| 대상 푸시 | **P-01** 사진 + **P-04** 텍스트 + **P-05** 배경 변경 |
| 기본값 | **OFF** |
| OFF 시 | 지금처럼 활동 1건 = 알림 1건 |
| ON 시 | 첫 알림은 즉시, 이후 10분 동안의 활동은 모아서 P-06 1건으로 발송 (상위 §2.6).  |
| 전환 | 즉시 반영, 확인 없음.  |

##### 3.3 설정값 저장

- **계정 단위로 서버에 저장**한다. 단일 기기 로그인이라 기기를 바꿔도 설정이 유지된다.

- 탈퇴 후 재가입은 신규 이용자로 보고 기본값으로 초기화한다 (상위 E-13).

- 두 토글은 서로 독립이다. 한쪽 설정이 다른 쪽에 영향을 주지 않는다.

##### 3.4 상태별 화면

| 상태 | 화면 |
| --- | --- |
| 기본 (OS 알림 허용) | 토글 2개 활성 |
| OS 알림 꺼짐 | 상단 안내 영역 노출 + 토글 2개 비활성(저장된 값만 표시, 조작 불가). 상위 정책 §3.3 예외 |
| 저장 실패 | 스위치를 바꾸기 전 상태로 되돌리고 토스트 노출 |

**OS 알림 꺼짐 안내 문구(안)**

```plain text
제목: 기기 알림이 꺼져 있어요
본문: 알림을 받으려면 기기 설정에서 파르페 알림을 허용해 주세요
버튼: [설정으로 이동]
```

- `[설정으로 이동]` → OS의 파르페 앱 알림 설정 화면으로 이동

**저장 실패 토스트 문구(안)**

```plain text
설정 저장에 실패했어요, 나중에 다시 시도해 주세요
```

- 토스트는 공통 노출 위치(y 121)를 따른다.
