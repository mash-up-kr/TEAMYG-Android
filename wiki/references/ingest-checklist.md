# ingest 체크리스트

이 문서는 절차서다. 근거 우선순위와 판본 상태(`status`) 값의 정의는
`wiki/conventions.md` §1·§2를 따른다 — 여기서 되풀이하지 않는다.

## 0. 시작 전

- `python3 wiki/script/ingest_cache.py --list`를 실행해 아직 처리되지 않은
  `wiki/raw/` 파일 목록을 확인한다.
- 목록이 비어 있으면 ingest할 것이 없다. 멈춘다.

## 1. 소스 단위로 처리한다

`wiki/raw/` 파일 하나마다 아래 2·3·4단계를 처음부터 끝까지 반복한다. 여러 소스를
한꺼번에 섞어 처리하지 않는다 — 판본 관계와 모순 판정은 소스 단위로 이뤄져야
나중에 무엇이 왜 그렇게 되었는지 추적할 수 있다.

## 2. 분석 단계 — 생성 전에 반드시 글로 정리할 것

페이지를 만들기 전에 아래 5가지를 문장으로 먼저 정리한다. 정리 없이 바로
페이지 생성으로 넘어가지 않는다.

1. **엔티티·개념 후보와 생성 여부** — 이 소스에서 새로 등장하거나 기존 서술을
   갱신하는 엔티티·개념 후보를 나열한다. 스쳐 지나가듯 한 번 언급된 이름까지
   전부 페이지로 만들지 않는다. 이 소스나 다른 소스에서 반복 등장하거나,
   `wiki/pages/purpose.md`의 핵심 질문에 직접 답하는 경우에만 페이지를 만든다. 그 밖은 관련
   페이지 본문의 서술로만 남긴다.
2. **판본 관계** — 이 소스가 기존 소스를 대체하는가, 아니면 기존 소스에 의해
   이미 대체되는가. 부분 대체(`partial`)라면 정확히 어느 범위만 대체되는지
   문장으로 적어 둔다. `status` 필드 값과 필수 부속 필드(`superseded_by`,
   `scope`)의 규칙은 `conventions.md` §2를 그대로 따른다.
3. **기존 위키와의 모순** — 새 소스의 주장이 기존 `concepts/`·`entities/`·
   `sources/` 페이지와 어긋나는 지점이 있는지 확인한다. 있으면 어느 페이지와
   무엇이 어긋나는지 적는다. 생성 단계에서 해당 페이지의 `## 미결` 섹션과
   상충 인라인 마커로 반영한다(마커 형식은 `conventions.md` §8).
4. **해소되는 기존 미결과 하류 반영 대상** — 이 소스가
   `wiki/open-questions.md`의 기존 항목을 해소하는지 확인한다.
   해소된다면 그 항목을 인용하는 다른 페이지 중 갱신이 필요한 곳(하류)을
   나열한다.
5. **동음이의 위험** — 새로 만들 페이지명 후보가 `wiki/` 전역의 기존 파일명과
   겹치지 않는지 확인한다. 파일명 유일성 규칙은 `conventions.md` §4.

## 3. 생성 단계 — 순서 고정

아래 순서로 만든다. 순서를 바꾸지 않는다 — 뒤 단계가 앞 단계의 산출물을
링크로 참조하므로, 거꾸로 하면 만드는 중간에 깨진 링크가 생긴다.

1. `wiki/pages/sources/src-<원본stem>.md`
2. `wiki/pages/entities/*.md`
3. `wiki/pages/concepts/*.md`
4. `wiki/pages/overview.md` 갱신
5. `wiki/pages/index.md` 갱신
6. `wiki/log.md`에 기록

## 4. 소스 하나가 끝날 때마다

- `python3 wiki/script/ingest_cache.py --record <raw 경로>`를 실행해 처리
  완료를 기록한다. 소스 하나를 끝낼 때마다 실행한다 — 여러 소스를 처리하고
  마지막에 몰아서 기록하지 않는다. 중간에 중단되면 이미 끝낸 소스와 아닌
  소스가 구분되지 않게 된다.

## 5. 마지막에

- `python3 wiki/script/lint.py`를 실행하고 위반 0건을 확인한다. 위반이
  남아 있으면 ingest가 끝난 것이 아니다. 코드별 대응은
  `wiki/references/lint-rules.md`를 본다.
- 그래프를 1회 다시 만든다 — 시점과 명령은 `wiki/CLAUDE.md`의 "작업 후" 절이
  정본이다. 돌리지 않으면 다음 lint부터 `그래프stale` 하나만 뜨고 나머지 세
  그래프 신호는 판정 자체가 생략된다.

## 멈출 조건

아래에 해당하면 생성을 멈추고 사용자에게 확인한다. 짐작으로 채우지 않는다.

- **판본 관계가 불분명할 때** — 두 소스 중 어느 것이 최신인지, 부분 대체라면
  범위가 정확히 무엇인지 소스 내용만으로 판정할 수 없을 때.
- **모순이 발견됐는데 어느 쪽이 옳은지 데이터로 판정되지 않을 때** — 임의로
  한쪽을 정본으로 정하지 않는다. 해당 페이지의 `## 미결`에 남기고
  `open-questions.md`에 등록한 뒤 다음 소스로 넘어간다.

## 연관

  구성)
- `wiki/references/lint-rules.md` — 마지막 lint 위반 대응
- `wiki/script/ingest_cache.py`, `wiki/script/lint.py`
