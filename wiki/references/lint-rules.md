# lint 규칙 대응표

`wiki/script/lint.py`와 `wiki/script/check_status.py`가 내는 모든 코드와,
발견했을 때 어떻게 대응하는지를 담는다. 각 규칙이 무엇을 의미하는지(예:
`status`가 가질 수 있는 값, frontmatter 필수 필드)는 `wiki/conventions.md`가
정본이다. 이 문서는 그 규칙을 다시 설명하지 않고, 코드가 뜨면 무엇을 하는지만
적는다.

## 코드 목록을 다시 뽑는 법

```bash
grep -n 'Finding(' wiki/script/lint.py wiki/script/check_status.py
```

주의: `Finding("violation", "코드", ...)` 호출이 여러 줄에 걸쳐 있는 경우가
많다. 첫 인자와 코드 문자열이 한 줄에 없으면 단순 grep으로는 코드를 놓친다.
아래 표는 lint.py·check_status.py 전체를 읽어서 뽑은 것이다 — 코드가 바뀌면
grep 결과만 보지 말고 두 파일을 다시 읽는다.

## 경고와 위반의 차이

- **위반**은 종료 코드를 1로 만든다. 커밋 전에 반드시 0건이어야 한다.
- **경고**는 종료 코드에 영향을 주지 않는다. 판단이 필요하다는 신호일 뿐 차단
  사유가 아니다. 약연결(인바운드 1건)과 개인 식별 정보(이메일·전화번호·
  로컬 절대경로 등)가 여기 속한다.

## 자동 수정 가능 여부를 나누는 기준

"자동 수정 가능"은 정답이 하나로 정해져 있어 판단 없이 기계적으로 고칠 수
있는 경우만 가리킨다. 값을 무엇으로 채울지 콘텐츠 판단이 필요하면 사람 또는
LLM이 문맥을 보고 채운다 — 스크립트가 대신 지어내지 않는다.

**민감 데이터는 예외적으로 별도 규칙이다.** 위반 등급(자격증명류)이든 경고
등급(개인 식별 정보)이든, **자동 삭제·마스킹은 금지한다.** 값이 무엇인지는
기계가 판단할 수 있어도, 지워도 되는지는 사람의 승인 없이 넘길 수 없는
결정이기 때문이다. 위치를 보고하고 사용자에게 확인을 구한다.

### 커뮤니티 이름이 비어 보일 때

위 세 신호는 커뮤니티를 **정수**로만 본다 — 이름은 사람이 읽기 위한 것이라
비어 있어도 판정에 아무 영향이 없다. 그래프가 커져 이름 없는 커뮤니티가
거슬리면 `graphify label . --backend=claude-cli --missing-only`로 이름 없는
것만 다시 붙인다(스펙 §5.6). 신호를 고치려고 돌리는 명령이 아니다.

## check_status.py — 코드 `status`

`check_status.py`가 내는 모든 finding은 코드가 `status` 하나로 통일돼 있다.
메시지로 어느 검사에서 났는지 구분한다.

| 검사 | 잡는 것 | 대응 |
|---|---|---|
| 필드 검사 | `status` 누락·허용값 밖 / `superseded`·`partial`인데 `superseded_by` 없음 / `partial`인데 `scope` 없음 / `current`인데 `superseded_by` 있음 | 값을 채우거나 정정한다. 필드 규칙 자체는 `conventions.md` §2. 어떤 값이 맞는지는 소스 내용을 봐야 하므로 사람/LLM 판단 |
| 참조 검사 | `superseded_by`·`supersedes`가 가리키는 대상이 `wiki/pages/sources/`에 없음(stem 단독 매칭, 도메인 구분 없음) | 오타 정정 또는 대상 페이지 확인. 판단 필요 |
| 체인 검사 | `superseded_by`를 따라가도 `current`에 도달하지 못함 / 체인에 사이클 존재 | 체인 어딘가의 값이 틀렸다는 뜻이다. 소스들을 다시 읽고 관계를 바로잡는다. 판단 필요 |
| 역참조 검사 | `supersedes` ↔ `superseded_by`가 양방향으로 일치하지 않음 | 누락된 쪽에 값을 추가한다. 어느 쪽이 최신 사실인지 확인 후 진행 — 판단 필요 |
| index 투영 검사 | `wiki/pages/index.md`의 `**현행 정본**`/`🔁` 표기가 frontmatter `status`와 어긋남 | **frontmatter가 정답이다**(`conventions.md` §2). index 쪽 표기를 frontmatter 값에 맞춰 다시 쓴다. 정답이 이미 frontmatter에 있으므로 **자동 수정 가능** |

`status` 코드 중 유일하게 index 투영 검사만 자동 수정 대상이다. 나머지
`status` 하위 검사는 전부 소스 내용에 대한 판단이 필요하다.
